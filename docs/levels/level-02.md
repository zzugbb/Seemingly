# 第 2 关 · 看似

## 关名、章节、教学点

- 第一章「看似」，第 2 关。
- 教学点：静态错觉连接，往上和往下各一次。

## 原来如此

低处的步道直接「接上」了四层高的塔顶；从塔顶再往回看，又「接上」了另一座岛上的中层步道。路并不相连，只是看起来相连。

## 积木清单

- 西岛：地面 `x -1～3、z -1～3`，高度 `-1`；陶土步道（高度 0）`(0,0,2)` 起点、`(0,0,1)`、`(1,0,1)`、`(2,0,1)`。
- 中央高塔：地面 `x 5～8、z 3～6`（底部岩层深 4）；粉色柱子 `(6,0..2,4)`、`(7,0..2,4)`、`(6,0..2,5)`；塔顶路面（高度 3）`(6,3,4)`、`(7,3,4)`、`(6,3,5)`。
- 东岛：地面 `x 4～8、z 0～1`；陶土柱 `(5,0,1)`、`(6,0,1)`、`(7,0,1)`；步道（高度 1）`(5,1,1)`、`(6,1,1)`、`(7,1,1)`，`(7,1,1)` 是终点。

## 其他元素

无。

## 标准解法

1. 走到 `(6,3,5)`：沿西岛步道走，跨过第一处错觉连接（高度 0 → 3）上到塔顶，拿光点。
2. 走到 `(7,1,1)`：沿塔顶走到另一侧，跨过第二处错觉连接（高度 3 → 1）下到东岛，点亮灯笼。

## 干扰与陷阱

玩家第一眼通常不相信低处能走上塔顶。点一下塔顶路面就会发现可以，这正是本关要建立的直觉。

## 参考实现

```ts
import { defineLevel } from './builders'

export default defineLevel({
  id: 'level-02',
  title: '看似',
  chapter: 1,
  hints: ['看起来连着，就能走过去'],
  build: (b) => {
    b.island({ x: [-1, 3], z: [-1, 3], y: -1 })
    b.path([0, 0, 2], 'terracotta')
    b.path([0, 0, 1], 'terracotta')
    b.path([1, 0, 1], 'terracotta')
    b.path([2, 0, 1], 'terracotta')

    b.island({ x: [5, 8], z: [3, 6], y: -1, depth: 4 })
    b.column({ x: 6, z: 4, from: 0, to: 2 }, 'rose')
    b.column({ x: 7, z: 4, from: 0, to: 2 }, 'rose')
    b.column({ x: 6, z: 5, from: 0, to: 2 }, 'rose')
    b.path([6, 3, 4], 'rose')
    b.path([7, 3, 4], 'rose')
    b.path([6, 3, 5], 'rose')
    b.orb({ tile: [6, 3, 5] })

    b.island({ x: [4, 8], z: [0, 1], y: -1 })
    b.column({ x: 5, z: 1, from: 0, to: 0 }, 'terracotta')
    b.column({ x: 6, z: 1, from: 0, to: 0 }, 'terracotta')
    b.column({ x: 7, z: 1, from: 0, to: 0 }, 'terracotta')
    b.path([5, 1, 1], 'terracotta')
    b.path([6, 1, 1], 'terracotta')
    b.path([7, 1, 1], 'terracotta')

    b.start([0, 0, 2])
    b.goal([7, 1, 1])
  },
  solution: [
    { type: 'walk', to: [6, 3, 5] },
    { type: 'walk', to: [7, 1, 1] },
  ],
})
```

## 实现备注

- 塔身可见侧面加 2～3 个窗洞，例如 `(6,1,5)` 的 `z` 面、`(7,1,4)` 的 `x` 面。
- 截图检查：西岛步道尽头与塔顶、塔顶与东岛步道，在画面上都要看起来相连。
