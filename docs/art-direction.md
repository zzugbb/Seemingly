# 美术方向

> 小样画面已确认可行。新增画面元素时，按本文的规格和配色执行。

## 风格

暖色、低饱和的积木世界，漂浮在黄昏的天空里。画面来自几何体、配色和光影，不依赖精细模型。

- **积木感**：方块带小圆角，相邻方块之间留有细缝，像真的积木拼起来。
- **安静**：画面元素少，留白多，动效都很慢。
- **温暖**：主色是陶土、沙色、玫瑰粉；冷色只用青绿，专门标记机关。

参考方向：《纪念碑谷》的构图和留白、《Townscaper》的温暖配色。只参考气质，不借用任何素材。

用色规则：

- **金色只用于可交互或可收集的东西**：把手、压板边框、灯笼、光点。玩家看到金色就知道可以点、可以踩或可以捡。
- **青绿只用于会动的积木**，让玩家一眼看出机关范围。
- 路面一律有浅色顶板，和结构积木区分开。

## 积木与场景

- 积木尺寸 0.98，圆角 0.07，所有积木共用同一份几何体。
- 路面顶板 0.84 见方、厚 0.12，中心和积木顶面齐平；悬停时抬起 0.03 并换成 cream。
- 岛屿底部是逐层收窄的阶梯岩层，每层高 0.62，颜色从沙色过渡到深紫。
- 装饰物：低多边形树、小花、拱形窗洞、飘动的云、漂浮的光点。摆放规则见 [level-design.md](level-design.md#构图)。

## 角色

小样中的小人太小，白色身体和米色路面几乎同色，看不清楚。正式版按以下规格重做（T2.1）：

| 部位 | 规格 |
| --- | --- |
| 总高 | 约 0.95 格（小样约 0.88） |
| 身体 | 上窄下宽的圆台，底部半径 0.24，顶部半径 0.12，高 0.48，颜色 plumDeep |
| 头 | 球体，半径 0.16，颜色 cream |
| 眼睛 | 两个半径 0.025 的小球，颜色 plumDeep，位于头部正面偏上 |
| 帽子 | 圆锥，半径 0.17，高 0.34，颜色 terracotta，向后微倾 |
| 脚下影子 | 半径 0.28 的圆形，颜色 plumDeep，不透明度 0.25，贴在路面顶板上 |
| 行走 | 身体左右摆动 ±6 度，上下起伏 0.06 |
| 到达 | 停顿 0.15 秒，身体轻压缩后回弹 |
| 待机 | 缓慢呼吸（纵向缩放 ±2%） |

验收标准：在每一块路面上、手机尺寸（375×667）的截图里，都能立刻看清小人的位置和朝向。

T6.12v1 补充：游玩时，被建筑挡住的身体、头和帽子以 cream 色、0.7 不透明度的平面剪影显示，不增加发光、粒子、提示箭头或呼吸闪烁。只绘制被场景挡住的片段，已经可见的角色保持原材质；角色自身的重叠不触发剪影。剪影与身体共用同一变换和几何体，乘坐、行走、撤销及减少动态效果时保持对齐。标题和选关预览关闭。此效果只解决角色定位，不代表建筑相交已经修复；第四至六关运动净空留在 T6.12v2。

## 机关的样子

- **转盘**：桥臂积木用 tealLight，下方有一圈青绿圆盘和金色细边；把手是金色转轮，装在立柱可见侧面上，转动时转轮同步旋转。
- **平移台**：积木用 tealLight；把手是金色拉杆，每次操作拉杆在两个角度之间来回扳动。
- **压板**：普通路面顶板上加一圈金色边框（内缩 0.06，宽 0.05）；小人踩上时顶板下沉 0.03 再回弹；`once` 压板用过后边框变成 plum。
- **把手抖动**：被阻止时沿水平方向快速抖动 0.5 秒，幅度 0.04。

## 灯笼（终点）

- 立在终点路面上：细柱高 0.5，顶部挂一个圆角小方灯，宽 0.22、高 0.28。
- **未点亮**：灯框 cream，灯芯 plum。
- **点亮**：灯芯变为 glow 并发光，附近加暖色点光源，光点粒子散开 1 秒后转为缓慢环绕。
- **亮度递增**（改版）：每收集一个必需光点，灯芯亮度提高一级（从 plum 向 glow 插值）；必需光点不齐就抵达时，灯芯快速闪两下。

## 光点（改版新增）

- **必需光点**：半径 0.09 的发光小球，颜色 glow，悬在路面顶板上方 0.35，上下浮动 ±0.05（周期约 1.6 秒），周围少量光点粒子。
- **选做光点**：同样的小球，外面多一圈缓慢旋转的 cream 细环（半径 0.16），让玩家一眼区分。
- **收集**：0.6 秒内缩小并沿弧线飞向灯笼，到达时灯笼亮度提高一级；减少动态效果时直接消失。
- 机关积木上的光点随积木一起转动或移动。

## 新机制的样子（改版新增）

| 元素 | 样子 |
| --- | --- |
| 积木箱 | 边长 0.72 的圆角方块，cream 色，四个上角各有一小块 glow 色角饰，表示可以推；放在路面顶板上 |
| 推不动 | 积木箱水平抖动 0.3 秒，幅度 0.04 |
| 切换门 | 两根细柱加一块横板，高 0.55，颜色 plum；打开时整体沉入顶板以下；有把手时把手装在附近结构积木上，和门之间不需要连线 |
| 按住门 | 样子同切换门，但横板中央有一个 glow 色小圆点，与按住压板呼应 |
| 触发压板 | 顶板一圈金色边框（首版样式） |
| 按住压板 | 金色双层边框，中央一块内缩的方形；被压住时内方块下沉 0.04 并保持 |
| 单向格 | 顶板上画一个 glow 色的 V 形箭头，指向可进入的屏幕方向；箭头贴在顶板上，不凸起 |
| 限次把手 | 把手旁一排小圆点（半径 0.03），剩余为 glow、已用为 plum；用完后把手整体变成 plum |
| 巡逻者 | 半径约 0.22 的圆滚滚小生物，身体 rose 色，两只 plumDeep 小眼睛，没有手脚；每走一格轻跳一下，被挡住时原地小幅蹦跳 |

规则：

- 巡逻者不能用 glow 色和青绿色，避免被误认为可交互的东西或机关。
- 积木箱比路面小一圈，让玩家一眼看出它是「放在路上的东西」，而不是路面本身。

## 撤销与提示（改版新增）

- HUD 按钮沿用胶囊样式，文字为「撤销」「提示」；没有可撤销的步骤时「撤销」半透明不可点。
- **提示高亮**：目标路面的顶板换成 glow 色并缓慢脉动（不透明度 0.6～1，周期 0.8 秒），持续 2 秒；目标是把手时，把手放大 1.15 倍并同样脉动。
- 无法通关时不高亮，只显示提示文字。

## 光影

- 半球光（天空 `#fff1df`、地面 `#8b6f9c`，强度 0.95）加环境光（强度 0.2）提供底色；平行光从左上前方打出主光和阴影，强度 2.5。
- 三个可见面明暗分明：顶面最亮，左前面次之，右前面最暗。
- 阴影贴图 2048；低画质关闭阴影。
- 背景是 CSS 渐变（米白、蜜桃、淡紫），四角轻微暗角，不在 3D 场景里画天空。

## 界面

- 界面文字为简体中文。T6.12o2 的标题入口目标以「积木错位」为主标题，Seemingly 为辅助品牌行；文字与真实第一关建筑独立分区，保留原有配色、固定视角与系统字体。标题已由 t2 实现，u2 移除重复样段入口。
- 字体用系统字体（苹方、冬青黑体、微软雅黑）。
- 按钮与提示条沿用圆角胶囊，正文 `#4a3a52`。T6.12o2 的主入口按钮用该深色底配 cream 文字，次按钮保留浅色底；标题／选关的小字与评价按入口稿提高对比，不改变游戏 HUD。
- T6.12v4：首次教学沿用原底部胶囊，一次一句，学会后不保留空白底栏；运动和到位文字仅临时出现，不添加箭头、闪烁或新动效。
- 提示不遮挡场景中央；通关横幅在顶部，延迟 0.5 秒淡入。
- 手机端：提示条纵向排列，按钮触控区域不小于 44×44 像素。

## 第三、四章回应（T6.13a设计稿）
