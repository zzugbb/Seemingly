# 路线图

## 开发前准备清单

正式开发前需要先确认或完成：

- [ ] 确认中文名：「积木错位」还是「看似」。
- [ ] 确认许可证：代码沿用 MIT 和其他项目保持一致，还是另选；美术和关卡是否单独约定。
- [ ] 在仓库设置里把 GitHub Pages 的来源设为 GitHub Actions。
- [ ] 本机为这个仓库配置 git 用户名和邮箱。
- [ ] 审阅[设计稿](design.md)，确认机关清单和关卡规划。
- [ ] 审阅[美术方向](art-direction.md)，确认角色优化方向。

## 已知问题（来自小样）

- 小人太小，颜色和路面接近，看不清。
- 转轮的点击区域只有一个小圆盘大小，手机上可能不好点，尚未真机验证。
- 关卡只支持一个转盘，机关不能组合。
- `World.tsx` 混合了状态、交互和渲染，继续加功能前需要拆分。
- 构建时提示单个脚本超过 500 KB，暂不影响使用。
- 自动化浏览器在后台标签页时会暂停动画帧，截图测试要注意这一点，这不是游戏本身的问题。
