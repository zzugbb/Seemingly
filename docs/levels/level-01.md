## 关名、章节、教学点

第一章「看似」，关名「启程」。只教点击浅色路面行走、进入路面自动收集光点、集齐必需光点再点灯；不提前引入机关、乘坐、推动和遮挡谜题。通过两次高低错觉跨越让玩家亲眼看见“看起来接上就能走”，正式的静态错觉教学仍在第二关。

## 原来如此

看起来接上步道的高塔真的能走上去；两侧的光点可以自由选择顺序，最后回到入口旁点灯。

## 屏幕草图

屏幕 `(a,b)=(x-y,z-y)`，数字是路面高度，`o` 必需光点、`@` 起点、`G` 灯笼。

```text
b\a   0    1    2    3    4
-1    0    0o
 0    0
 1    0    0    0    2    2o
 2    0    0G
 3    0@
```

`(2,1)` 的低步道与 `(3,1)` 的高塔入口形成错觉连接；向屏幕下方走时由高度 0 升到 2，满足遮挡规则。返回沿相同接口离开高塔。灯笼不在通往两个光点的必经路径上，不能一次点灯靠自动寻路把光点全部捡完。

## 积木清单

- 西岛：`x -1～3、z -1～3、y=-1、深度 2`。
- 陶土路面：`(0,0,3)`、`(0,0,2)`、`(0,0,1)`、`(1,0,1)`、`(2,0,1)`；左侧岔路 `(0,0,0)`、`(0,0,-1)`、`(1,0,-1)`；入口旁灯笼台 `(1,0,2)`。
- 东岛：`x 4～7、z 2～4、y=-1、深度 2.8`。
- 玫瑰粉双格高塔：`x=5、6，z=3，y=0～1` 实心立柱，路面分别 `(5,2,3)`、`(6,2,3)`。一座连续建筑，不增加第三座小岛。
- 起点 `(0,0,3)`，终点 `(1,0,2)`。

## 其他元素

无箱子、压板、门、单向格或巡逻者。四处装饰：西岛树 `(-1,-1,0)`、花 `(3,-1,3)`、东岛树 `(7,-1,4)`、高塔 z 面窗 `(5,0,3)`；不挡路、不暗示其他可行走格。

## 标准解法

1. 走到 `(1,0,-1)`：收集庭院光点。
2. 走到 `(6,2,3)`：跨过步道与高塔的错觉接口，收集第二处光点。
3. 走到 `(1,0,2)`：从高塔返回入口旁，点亮灯笼。

两个光点的收集顺序可互换，仍为 3 步；不将某一顺序设成隐含正确答案。

## 干扰与陷阱

- 直接点击入口旁灯笼会抵达，但提示「还差 2 个光点」，点亮目标保持可见。
- 只拿一处光点就回来时提示「还差 1 个光点」，不会卡死；撤销可恢复动作前位置与光点。
- 沙色岛屿和粉色塔侧面不是路面；不额外铺浅色顶板。
- 无永久死局，不用遮挡断路为难新玩家；两处光点开局均可见。

## 参考实现

```ts
import { defineLevel } from './builders'

export default defineLevel({
  id: 'level-01',
  title: '启程',
  chapter: 1,
  revision: 2,
  soundtrack: 'courtyard',
  hints: ['点击浅色路面，小人会走过去', '集齐两处光点，再回到灯笼'],
  build: (b) => {
    b.island({ x: [-1, 3], z: [-1, 3], y: -1, depth: 2 })
    for (const pos of [
      [0, 0, 3],
      [0, 0, 2],
      [0, 0, 1],
      [1, 0, 1],
      [2, 0, 1],
      [0, 0, 0],
      [0, 0, -1],
      [1, 0, -1],
      [1, 0, 2],
    ] as const)
      b.path([...pos], 'terracotta')
    b.orb({ tile: [1, 0, -1] })
    b.island({ x: [4, 7], z: [2, 4], y: -1, depth: 2.8 })
    for (const x of [5, 6]) {
      b.column({ x, z: 3, from: 0, to: 1 }, 'rose')
      b.path([x, 2, 3], 'rose')
    }
    b.orb({ tile: [6, 2, 3] })
    b.tree([-1, -1, 0])
    b.flower([3, -1, 3])
    b.tree([7, -1, 4])
    b.window({ pos: [5, 0, 3], face: 'z' })
    b.start([0, 0, 3])
    b.goal([1, 0, 2])
  },
  solution: [
    { type: 'walk', to: [1, 0, -1] },
    { type: 'walk', to: [6, 2, 3] },
    { type: 'walk', to: [1, 0, 2] },
  ],
})
```
