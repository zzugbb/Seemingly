## 玩法

在等距视角下，两块不相邻的积木只要在屏幕上看起来接在一起，小人就能从一块走到另一块。玩家通过转盘和平移台改变「看起来」的样子，为小人拼出一条通往终点的路。

1. 点击路面，小人自动走过去；看起来相邻的路面就能连通。
2. 点击金色转轮或拉杆操作转盘、升降台；小人站在机关上时可以随它移动。
3. 收集全部必需光点后抵达灯笼即可通关；选做光点用于全收集评价。进度保存在浏览器本地。

电脑和手机都用点击操作。`Z` 撤销，`H` 提示，`R` 重新开始，`Esc` 返回选关；右上角可切换静音。首次交互后播放柔和的合成音效与环境和弦，静音选择也会保存。

需要支持 WebGL2 的浏览器。手机默认使用低画质，也可用 `?quality=low` 或 `?quality=high` 指定画质；支持系统的「减少动态效果」设置。

## 技术亮点

- **屏幕上的连通**：用 `(x - y, z - y)` 判断路面是否相邻，以固定等距正交视角呈现跨越三维距离的错觉连接。
- **可验证的关卡**：纯 TypeScript 模拟器与渲染分离，当前关卡均附确定解法，由 Vitest 校验连通、遮挡、机关规则与难度目标。
- **代码生成的积木世界**：圆角积木、岛屿岩层、树木、角色与灯笼由几何体组成，共享积木几何体并缓存材质。
- **实时合成声音**：Web Audio 生成脚步、机关、走不通、灯笼琶音与环境和弦，无外部音频文件。
- **打开即玩**：纯静态站点，无账号、后端、统计或广告；进度与静音保存在浏览器本地。

首版性能基线为首屏压缩资源约 326 KB、九关解法全过程最高 360 次绘制调用（含阴影）；这些不是当前六关的重新测量结果。测量范围与真机帧率待验证项见[性能检查](docs/performance.md)。

## 本地运行

需要 Node.js 24（见 `.nvmrc`）。

```bash
npm install
npm run dev           # http://127.0.0.1:5180
npm run typecheck     # 类型检查
npm test              # 单元测试
npm run metrics       # 关卡难度指标表
npm run format        # 格式化
npm run format:check  # 检查格式
npm run build         # 生成静态站点到 dist/
npm run preview       # 预览构建产物
```

GitHub Actions 在推送到 `main` 后执行类型检查、格式检查、测试和构建，再发布到 GitHub Pages 的 `/Seemingly/` 子路径。开发进度以路线图为准，首版截图与性能记录保留为历史基线，在线版本随发布更新。

`npm run metrics` 输出全部关卡的最少步数、全收集最少步数、可达状态数、死局数、随机通关率、标准解法中的错觉连接数与取舍次数。随机模拟固定种子为 `20261016`，每关运行 500 次，步数预算采用难度目标中的设置，未设置时使用 30 步。首版九关只提供指标基线，不登记难度目标；重制关卡由设计者在 `src/game/levels/targets.ts` 填写目标后，测试会强制检查指标及标准解法最优步数。

## 技术栈

- Vite + React 19 + TypeScript
- Three.js + React Three Fiber + drei
- 画面全部由代码生成，声音用 Web Audio 实时合成，不依赖任何外部素材
- 纯静态站点，通过 GitHub Actions 发布到 GitHub Pages

## 目录结构

```text
Seemingly/
├── AGENTS.md            AI 开发指南
├── docs/                设计、决策、架构、关卡规范、美术、路线图
├── public/              原样拷贝到站点根目录的静态资源
└── src/
    ├── main.tsx         入口
    ├── app/             页面外壳与界面
    ├── audio/           Web Audio 引擎、合成音效与环境和弦
    └── game/
        ├── core/        纯逻辑：屏幕坐标、连通、寻路、移动（不依赖 Three.js）
        ├── levels/      关卡数据与类型
        └── render/      3D 场景、角色、装饰、配色
```

目标目录和模块职责见[架构说明](docs/architecture.md)。
