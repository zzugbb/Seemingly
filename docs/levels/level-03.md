# 第 3 关 · 错位

## T6.12g 校准

按用户授权持续校准前六关。本关是第一章章末，保留静态错觉与干扰岔路；将原本在主路自动收集的中层光点移到侧廊，要求主动规划三处收集与点灯，最少 4 步。五座地面基座收拢为三组，其他关卡不动。

## 关名、章节、教学点

第一章「看似」第三关，教学静态错觉网络、斜对角不相连、检查所有收集目标。无新机关，不把自动寻路、收集规则或遮挡规则改成关卡特例。

## 原来如此

最近的两条路只是斜对角挨着，必须回到入口从另一侧绕上去；点远塔虽然会经过中层主路，却不会自动绕进侧廊替你拿光点。

## 屏幕草图

`(a,b)=(x-y,z-y)`，数字为路面高度，`o` 必需光点、`@` 起点、`G` 灯笼。

```text
b\a   0   1   2   3   4   5   6   7
-1        0   0o      1o
 0    0   0       1   1   1   2   2G
 1    0           3       4   4o
 2    0@  0   0   3
```

岔路 `(2,-1)` 与中层起点 `(3,0)` 仅斜对角接近；`(3,-1)` 为空，不能抄近路。低步道 `(2,2)` 与三层入口 `(3,2)`、三层出口 `(3,1)` 与中层 `(3,0)`、中层 `(5,0)` 与四层 `(5,1)`、四层 `(6,1)` 与灯笼廊 `(6,0)` 是高低错觉接口。中层末端 `(5,0)@1` 与灯笼平台 `(6,0)@2` 也相接；标准寻路先借灯笼平台登远塔，再返回该平台，共五次错觉跨越。

## 积木清单

- 西岛：`x -1～3、z -2～3、y=-1`；低步道 `(0,0,2)` 起点、`(1,0,2)`、`(2,0,2)`，岔路 `(0,0,1)`、`(0,0,0)`、`(1,0,0)`、`(1,0,-1)`、`(2,0,-1)`。
- 双塔基座：`x 5～11、z 4～6、y=-1、深度 4`。三层塔路面 `(6,3,5)`、`(6,3,4)`，下方 `y=0～2` 补粉色柱；四层塔路面 `(9,4,5)`、`(10,4,5)`，下方 `y=0～3` 补粉色柱。
- 中层和灯笼共用基座：`x 4～10、z 0～3、y=-1、深度 2.8`。中层陶土路 `(4,1,1)`、`(5,1,1)`、`(6,1,1)`，下方 `y=0` 补垫块；侧廊 `(5,1,0)` 及下方垫块 `(5,0,0)`。
- 灯笼廊：`(8,2,2)`、`(9,2,2)`，下方 `y=0～1` 补沙色柱；后者为终点。

## 标准解法

1. 走到 `(2,0,-1)`：收集干扰岔路光点。
2. 走到 `(5,1,0)`：绕回入口，经三层高廊到中层侧廊，收集第二处。
3. 走到 `(10,4,5)`：从侧廊返回主路，经 `(8,2,2)` 的灯笼旁平台跨到远塔，收集第三处。
4. 走到 `(9,2,2)`：经高低接口抵达灯笼。

收集顺序不唯一。先去远塔也能完成，但中层侧廊须单独点进去；不会靠一次点击远塔自动收齐全部必需光点。

## 干扰与陷阱

- 岔路尽头和中层起点只在斜对角挨近，实际行走会绕回 `(0,0,2)` 再登三层廊；不要在空格补路。
- 从岔路直接点远塔，只会收集岔路和远塔两处，灯笼会提示还差 1 个光点；撤销可退回继续规划。
- 不使用不可逆机关或永久死局。每处光点和接口开局可见；不额外加常驻文字提示给出解法。
