# 第 4 关 · 转动

## T6.12h 校准

用户要求持续校准前六关。作为第二章章首，主线保留桥中心转动的清楚教学，最少仍为 6 步；原本顺路多走一步的选做光点改为下层乘台和远塔，需要多理解站位与乘坐，全收集 12 步。第五关仍正式教学主线乘坐。

## 教学点与原来如此

- 主线：桥朝东西时接入口和灯笼，转向南北后接北台，却断开东西。先站在静态桥中心，再切换朝向。
- 选做：上层短桥到不了远塔，必须先在入口侧登上下层长臂，再随同一转盘移动；远塔拿光后还要乘它回到北台，不能只在原地转桥。

## 屏幕草图

中心 `(a,b)=(4,2)`、高度 2。上层两桥臂：档 0 为 `(3,2)` 和 `(5,2)`，档 1 为 `(4,3)` 和 `(4,1)`，档 2 与档 0 对调，档 3 与档 1 对调。

```text
静态目标（屏幕坐标 / 高度）
入口末端 (2,2) / 0       北台光点 (4,0) / 1
中心     (4,2) / 2       灯笼     (6,2) / 3
选做远塔 (6,6) / 3

下层乘台（高度 1）
档 0 (5,0) → 档 1 (2,3) → 档 2 (5,6) → 档 3 (8,3) → 档 0
```

档 1 的下层乘台接入口末端；档 2 接选做远塔；档 0 接北台。它与桥中心有实心梁连接，但梁不是路面，不能从中心直接走到末端。

## 积木清单

- 入口地面 `x -1～3、z 0～3、y=-1`，陶土路 `(0,0,2)`、`(1,0,2)`、`(2,0,2)`。
- 中心与北台、灯笼共用地面 `x 4～10、z 0～6、y=-1、深度 3`。青绿中心柱 `(6,0～1,4)`，静态中心路面 `(6,2,4)`。
- 把手底座青绿实心 `(6,0,5)`、`(6,0,6)`、`(7,0,6)`、`(8,0,6)`，连接中心与前方控制位置。
- 北台 `(5,1,1)` 陶土路面，下方 `(5,0,1)`；灯笼塔 `(9,3,5)` 粉色路面，下方 `y=0～2` 粉色柱。
- 远塔地面 `x 7～10、z 7～10、y=-1、深度 4`；路面 `(9,3,9)`，下方 `y=0～2` 粉色柱。
- 起点 `(0,0,2)`，终点 `(9,3,5)`。

## 机关清单

只有一个 `bridge` 转盘，中心 `(6,2,4)`、初始档 0、顺时针，无联动。

| 积木下标 | 偏移 | 类型 |
| --- | --- | --- |
| 0 / 1 | `(-1,0,0)` / `(1,0,0)` | 上层桥臂路面 |
| 2 | `(0,-1,-3)` | 下层长臂末端路面 |
| 3 / 4 | `(0,-1,-1)` / `(0,-1,-2)` | 青绿实心连接梁 |

把手位于 `(8,0,6)` 的 z 面。原中心柱把手会被下层转臂遮住，因此移到前方底座；必须通过所有档位的可见性校验。

## 光点与其他元素

- `orb-0`：北台 `(5,1,1)`，必需。
- `orb-1`：远塔 `(9,3,9)`，选做。
- 无箱子、门、压板、单向格或巡逻者。
- 四处装饰：树 `(-1,-1,3)`、花 `(7,-1,9)`、窗 `(9,1,5)` 和 `(9,1,9)` 的 z 面。

## 主线标准解法

1. 走到 `(6,2,4)`：从入口登上静态中心。
2. 转动 bridge：转到档 1，接北台，东西断开。
3. 走到 `(5,1,1)`：收集必需光点。
4. 走回 `(6,2,4)`：回到静态中心。
5. 转动 bridge：档 2 重新接灯笼。
6. 走到 `(9,3,5)`：跨高低接口点灯。

## 全收集标准解法

| 步 | 动作 |
| --- | --- |
| 1 | bridge 一次，档 1，下层乘台接入口 |
| 2 | 走到 `(3,1,4)`，登 `bridge#2` |
| 3 | bridge 一次，乘到 `(6,1,7)` |
| 4 | 走到 `(9,3,9)`，取选做光点 |
| 5 | 走回 `(6,1,7)` 的下层乘台 |
| 6～7 | bridge 两次，经档 3 回档 0 |
| 8 | 走到 `(5,1,1)`，收集北台必需光点 |
| 9 | bridge 一次，档 1，上层桥接北台 |
| 10 | 走到 `(6,2,3)` 的上层桥臂 |
| 11 | bridge 一次，随上层桥臂转到西侧 |
| 12 | 经静态中心与东桥臂走到 `(9,3,5)` 点灯 |

第 10 步也可以走回静态中心再转。无论选择哪种，全收集必须使用下层乘台，不能只顺路多点一次。

## 干扰与陷阱

- 开局能走到灯笼，但缺必需光点会被拒绝；不能直接通关。
- 站在北台转桥后可能暂时断路，可以继续转回或撤销；零永久死局。
- 上层中心与下层乘台隔着不可走的实心梁；在中心转桥只能完成主线，拿选做要先登下层平台。
- 下层乘台途经档 3 时没有出口，需要继续乘到档 0；不要在途中寻找隐藏路。

```ts
import { defineLevel } from './builders'

export default defineLevel({
  id: 'level-04',
  title: '转动',
  chapter: 2,
  revision: 2,
  soundtrack: 'courtyard',
  hints: ['点击金色转轮，桥会转动 90 度'],
  build: (b) => {
    b.island({ x: [-1, 3], z: [0, 3], y: -1 })
    b.path([0, 0, 2], 'terracotta')
    b.path([1, 0, 2], 'terracotta')
    b.path([2, 0, 2], 'terracotta')

    b.island({ x: [4, 10], z: [0, 6], y: -1, depth: 3 })
    b.column({ x: 6, z: 4, from: 0, to: 1 }, 'teal')
    b.path([6, 2, 4], 'teal')
    for (const pos of [
      [6, 0, 5],
      [6, 0, 6],
      [7, 0, 6],
      [8, 0, 6],
    ] as const)
      b.solid([...pos], 'teal')
    b.rotator({
      id: 'bridge',
      pivot: [6, 2, 4],
      blocks: [
        { offset: [-1, 0, 0] },
        { offset: [1, 0, 0] },
        { offset: [0, -1, -3] },
        { offset: [0, -1, -1], kind: 'solid', color: 'teal' },
        { offset: [0, -1, -2], kind: 'solid', color: 'teal' },
      ],
      handle: { block: [8, 0, 6], face: 'z' },
    })

    b.solid([5, 0, 1], 'terracotta')
    b.path([5, 1, 1], 'terracotta')
    b.orb({ tile: [5, 1, 1] })

    b.column({ x: 9, z: 5, from: 0, to: 2 }, 'rose')
    b.path([9, 3, 5], 'rose')

    b.island({ x: [7, 10], z: [7, 10], y: -1, depth: 4 })
    b.column({ x: 9, z: 9, from: 0, to: 2 }, 'rose')
    b.path([9, 3, 9], 'rose')
    b.orb({ tile: [9, 3, 9], optional: true })

    b.tree([-1, -1, 3])
    b.window({ pos: [9, 1, 5], face: 'z' })
    b.flower([7, -1, 9])
    b.window({ pos: [9, 1, 9], face: 'z' })

    b.start([0, 0, 2])
    b.goal([9, 3, 5])
  },
  solution: [
    { type: 'walk', to: [6, 2, 4] },
    { type: 'operate', mechanism: 'bridge' },
    { type: 'walk', to: [5, 1, 1] },
    { type: 'walk', to: [6, 2, 4] },
    { type: 'operate', mechanism: 'bridge' },
    { type: 'walk', to: [9, 3, 5] },
  ],
})
```
