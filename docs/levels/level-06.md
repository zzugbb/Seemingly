## 状态与目标

T6.12t1 已实现；本稿由当前指定设计者在 T6.12v2 修订运动净空，取代旧坐标稿。id 为 level-06、revision 4，第二章，courtyard 声景。**西桥送出，借东桥取光，再经外角返回西桥远端，最后随长臂转向灯塔。** 主线 12 步、全收集 14 步。

第五关发现“人离台、空台让位”；本关继续强调两桥接力与返程站位，不重复降台显露。不增加机关、规则或旋转次数。西桥#0 为近端、#1 为远端，二者实际高度均为2；旧稿称“高台”的地方改称远端，避免把投影高低写成真实层差。

## 布局与调整

west 保持轴 `(4,2,4)`、初始档1，#0 偏移 `(-1,0,0)`、#1 `(-1,0,-5)`；六块下梁沿 `(-1,-1,-i)`、i=0..5连接两端，替代绕过东轴的巨大折梁。east 沿纵深放到 `(11,5,8)`、初始档0，保留 #0 `(-1,0,0)` 内端与 #1 `(-1,0,-1)` 外角。两桥间静态接驳面 `(7,3,5)`，下有支撑 `(7,2,5)`，投影 `(4,2)`，仅负责原来的两桥接驳。

前庭移至 x[6,14]、z[10,13]、y=4，起点 `(8,6,10)`、东庭 `(14,6,10)`、南庭 `(12,6,11)`；后塔基座 x[0,2]、z[-3,-1]、y=-1，终点 `(1,1,-2)`；北基座与侧梁保留，另有接驳小底座 x[5,5]、z[3,3]、y=-1。静态把手支座分别 `(6,5,13)`、`(14,5,11)` z面。分开实际纵深后，东桥外角绕行不再扫过固定落脚点或西桥。

必需光点仍在 east#1 与东庭；选做仍在东档1经内端可停靠的南庭。起点、南庭、东庭、接驳面与终点都有参考实现列出的支撑。三盏装饰灯、窗、花、树沿建筑迁移，无新增装饰机关。不得把两端间的实心梁铺成道路。

## 屏幕接点

`(a,b)=(x-y,z-y)`。西轴投影(2,2)，东轴(6,3)。起点(2,4)；静态接驳面(4,2)；南庭(6,5)；东庭(8,4)；终点(0,-3)。

| 路面 | 档0 → 1 → 2 → 3 |
| --- | --- |

| east#0 | (5,3) → (6,4) → (7,3) → (6,2) |

西档2经接驳面登东桥；东档3外角(7,2)接西档3远端(7,1)，内端(6,2)与西远端不直接相邻。静态接驳面不把返程接点合并；内端与外角自身相邻，西桥到位后允许自动寻路经外角登西远端，不强制多点一次外角。

## 主线标准解法（12 步）

| 步 | 动作 |
| --- | --- |
| 1 | `(4,2,5)` 登西近端 |
| 2 | west 一次到档2 |
| 3 | `(10,5,7)` 经接驳面登东外角，取移动光点 |
| 4～5 | east 两次到档2 |
| 6 | `(14,6,10)` 下桥收东庭必需光点 |
| 7 | `(12,5,9)` 改登外角 |
| 8 | east 一次到档3 |
| 9 | west 一次到档3（离西桥后也可提前操作） |
| 10 | `(9,2,3)` 登西远端 |
| 11 | west 一次到档0，载人转向后塔 |
| 12 | `(1,1,-2)` 点灯、前庭三灯回应 |

## 全收集标准解法（14 步）

走 `(4,2,5)` → west → `(10,5,8)` 经外角取光后登东内端 → west → east → 南庭 `(12,6,11)` 取选做 → `(11,5,9)` 返回内端 → east → 东庭 `(14,6,10)`（移动光点此前已沿途收集）→ `(12,5,9)` 改登外角 → east → `(9,2,3)` 西远端 → west → `(1,1,-2)`。

## 干扰、反事实与指标

乘西近端绕圈不能到远端；西桥未在档3时不能登西远端；到位后内端可自动经外角登西远端，与预先站在外角一样可12步完成。外角是必经接点，不是必须另点一次的站位。未收东庭光点不能点灯。禁用任一把手、将西远端改为solid、过滤乘坐操作均无解；过滤东档1路线含 east#0 的 walk 后，主线仍12步，全收集无解。收光、内端停靠、外角返程、载人转动、运动中拒绝行走、撤销与三灯回应均须测试。

## 运动与角色净空（T6.12v2）

仅修复实体结构与运动净空，固定镜头、屏幕连通、遮挡断路和乘坐规则不变，不加入三维行走碰撞。既有主线发现、必需／选做光点职责与 targets 保留。保持当前 revision，保留玩家已获评价；本轮没有新增评价条件或提高最少步数。

机关运动时角色在 0.12 秒内轻微收身到原高度的 94%，足底不动，到位后恢复；正常站立与呼吸不变，剪影跟随同一姿态。此姿态最多让出帽尖附近 0.06 格，不能掩盖身体与建筑相撞。净空检测同时检查收身开始、运动中、到位恢复站立，不能从第一帧就假定角色已收身。具体检测尺寸、轴承例外与采样限制见 [运动净空](../motion-clearance.md)。

验收须包括所有可达机关组合、合法站位的运动采样、主线和全收集、错误操作后的恢复、乘坐及撤销，以及桌面／手机实际点击和中间帧截图。规则、targets、音频和存档实现不改；T6.12 仍待用户整体试玩确认。
