# 第 1 关 · 启程

## 关名、章节、教学点

- 第一章「看似」，第 1 关。
- 教学点：点击路面行走；集齐光点才能点亮灯笼。

## 原来如此

步道的尽头，看起来直接接上了高塔塔顶，于是就真的能走上去。这一关不考错觉，只让玩家第一次「看到」它。

## 积木清单

- 西岛：地面 `x -1～3、z -1～3`，高度 `-1`。
- 陶土步道（高度 0）：`(0,0,3)` 起点、`(0,0,2)`、`(0,0,1)`、`(1,0,1)`、`(2,0,1)`；岔路 `(0,0,0)`、`(0,0,-1)`、`(1,0,-1)`。
- 东岛：地面 `x 4～6、z 2～4`，高度 `-1`。
- 粉色高塔：柱子 `(5,0..1,3)`，塔顶路面 `(5,2,3)` 是终点。

## 机关清单

无。

## 光点清单

| 编号 | 位置 | 类型 |
| --- | --- | --- |
| orb-0 | `(1,0,-1)` 岔路尽头 | 必需 |

## 其他元素

无。

## 标准解法

1. 走到 `(1,0,-1)`：岔路尽头拿光点。
2. 走到 `(5,2,3)`：沿步道走到尽头，跨过错觉连接走上塔顶，点亮灯笼。

## 干扰与陷阱

直接点灯笼会走到塔顶，但灯笼闪烁提示「还差 1 个光点」，引导玩家回头拿光点。

## 参考实现

```ts
import { defineLevel } from './builders'

export default defineLevel({
  id: 'level-01',
  title: '启程',
  chapter: 1,
  hints: ['点击路面，小人会走过去', '集齐光点，灯笼才会亮'],
  build: (b) => {
    b.island({ x: [-1, 3], z: [-1, 3], y: -1 })
    for (const pos of [
      [0, 0, 3],
      [0, 0, 2],
      [0, 0, 1],
      [1, 0, 1],
      [2, 0, 1],
      [0, 0, 0],
      [0, 0, -1],
      [1, 0, -1],
    ] as const)
      b.path([...pos], 'terracotta')
    b.orb({ tile: [1, 0, -1] })

    b.island({ x: [4, 6], z: [2, 4], y: -1 })
    b.column({ x: 5, z: 3, from: 0, to: 1 }, 'rose')
    b.path([5, 2, 3], 'rose')

    b.start([0, 0, 3])
    b.goal([5, 2, 3])
  },
  solution: [
    { type: 'walk', to: [1, 0, -1] },
    { type: 'walk', to: [5, 2, 3] },
  ],
})
```

## 实现备注

- 装饰建议放在西岛地面空格，例如 `(-1,-1,0)`、`(3,-1,3)`，以及东岛的 `(6,-1,4)`。不要放在步道的屏幕下方相邻处。
- 截图检查：开局时步道尽头与塔顶在画面上看起来是连着的。
