# 第 6 关 · 回环

## 状态、来源与任务

2026-10-21 **T6.12t1** 已按本稿替换正式第六关：title「回环」、revision 4、主线 12／全收集 14。仅第六关旧评价失效。独立样段与第五关叠庭保持不变。

本次只交付设计文档。参考实现已通过规则、求解器、全部结构校验和严格类型检查；使用现有 Scene、Hud 在临时页面预览桌面与手机，未修改运行关卡、targets、存档或音频。预览不是正式流程集成验收，也没有用户对新关卡趣味性的确认。总交接见 [opening-plan.md](../opening-plan.md)。

## 与第五关的衔接

| 项目 | 第五关「叠庭」 | 第六关「回环」 |
| --- | --- | --- |
| 主要发现 | 人下台后移动空台，让同一投影位置后方的路显露 | 从第一座桥低端出发，借第二座桥取光，再从另一接点返回第一座桥高端 |
| 操作关系 | 升降台让位、转盘接客，解决一次显露 | 西桥送出、东桥转运、离桥取光、选返程外角、西高台接回，形成接力 |
| 规划重点 | 先留下静态落脚点再降台 | 离开低桥后才能重布西桥；返程要在东桥外角，内端的落点不同 |
| 选做 | 上层侧翼连到西台 | 东桥第一次转动后的内端连南庭；中途改用这个端点，随后恢复外角返程 |
| 主线／全收集 | 11／12 | 12／14 |
| 收束 | 乘高台离开庭院 | 原先送人的西长臂从远左侧接到右侧，再载人转向后方灯塔，点亮前庭三灯 |

保留第五关的完整目标稿与独立样段，不把第五关降级，也不再把“退开东桥露出低处光点”作为第六关选做。两关使用同一 courtyard 声景，避免换关切回旧音乐。第六关不用升降、联动、门、箱子、新镜头或新规则；双桥协作是已经掌握的能力的组合。

主线没有要求靠遮挡显露发现下一处路。把手与所有光点开局可见；西高台开局在左上，和低桥之间没有内部可行走通道。空桥调整可以提前进行，不能为了固定标准解法而禁止合法的操作顺序。

## 关名、章节与原来如此

第二章章末，关名「回环」。**送我出发的低桥和接我回来的高台属于同一个机关；我要借另一座桥绕出去，改变返程站位，再回到它的另一层。**

与第四关同一转盘换臂相比，多了第二个独立运动系统和返回接点；与第五关相比，关键是两桥接力和端点轨迹，不能用“降台后出现路”的同一段过程替代。难度不靠增加无意义旋转次数来撑，仍限主线 12 步。

## 屏幕草图

`(a,b)=(x-y,z-y)`，`@` 起点、`G` 灯笼、`o` 必需、`O` 选做；数字为路面高度。以下列的是不同阶段的接点，不表示开局同时相连。

```text
灯笼 (0,-5)@2
   │ 西高台档0 (1,-5)@3  ← 西高台档3 (7,1)@3
西高台开局档1在 (-5,1)@3                ↑
                             东外角档3 (6,1)@2
西轴 (2,2)，高度2       东轴 (5,2)，高度2
西低桥档2 (3,2)@2 — 东内端档0 (4,2)@2 — 东外角档0 (4,1)@2，必需光点
西低桥开局档1 (2,3)@2
          │             东内端档1 (5,3)@2 — 南庭 (5,4)@2，选做
起点 (2,4)@3            东外角档2 (6,3)@2 — 东庭 (7,3)@2，必需光点
```

| 积木 | 档 0 → 1 → 2 → 3 | 高度 |
| --- | --- | --- |
| west#0 低桥 | (1,2) → (2,3) → (3,2) → (2,1) | 2 |
| west#1 高台 | (1,-5) → (-5,1) → (1,7) → (7,1) | 3 |
| east#0 内端 | (4,2) → (5,3) → (6,2) → (5,1) | 2 |
| east#1 外角 | (4,1) → (4,3) → (6,3) → (6,1) | 2 |

## 积木、机关和光点清单

- 三座基座：北侧 `x[1,8],z[0,1],y=-1,depth=2`；前庭 `x[1,9],z[5,8],y=0,depth=2.5`；灯塔 `x[1,3],z[-4,-2],y=-1,depth=3`。侧梁与中梁在 `z=2..4`，分别为 `(1,-1,z)`、`(9,0,z)`、`(4,-1,z)`。前庭比北基座高一格，不得统一压平。
- 静态路面：起点 `(5,3,7)`、东庭 `(9,2,5)`、灯塔 `(2,2,-3)`、南庭 `(7,2,6)`；下方玫瑰色柱子在参考实现中列全。两个实心轴均补到高度 2，轴没有顶板。
- west：中心 `(4,2,4)`，初始档 **1**；#0 偏移 `(-1,0,0)`，#1 偏移 `(0,1,-6)`；其余十块为实心折臂，凹口避开东轴；末端抬高一格支撑高台。把手 `(1,1,8)` z 面。
- east：中心 `(7,2,4)`，初始档 **0**；#0 偏移 `(-1,0,0)`，#1 偏移 `(-1,0,-1)`；把手 `(9,1,6)` z 面。两机关均无限次、独立、无联动。
- 两处必需光点：east#1 随桥移动、东庭 `(9,2,5)`；选做在南庭 `(7,2,6)`。没有旧 west#2 低处路面，不保留旧北台光点。
- 无箱子、门、压板、单向格、限次把手、巡逻者或 ending。
- 树 `(1,-1,0)`、花 `(8,0,7)`、灯塔 z 面窗 `(2,0,-3)`；装饰灯 `(2,0,7)`、`(8,0,6)`、`(1,-1,-3)`，沿用现有点灯／撤销表现，不参与规则。

完整坐标、kind 与索引以参考实现为准。折臂看起来连成一体，但实心面不能铺成道路；不能把 low/high 接通，也不能删去折梁来避开校验。全档位的屏幕范围刚好在 14×14 内，不能随意把基座外扩一格。

## 主线标准解法（12 步）

| 步 | 动作 | 用意 |
| --- | --- | --- |
| 1 | 走到 `(4,2,5)` | 登 west#0 低桥，开局西档 1 |
| 2 | west 一次 | 随低桥到西档 2，接上东内端 |
| 3 | 走到 `(6,2,3)` | 经东内端到 east#1 外角，取移动光点；离开西桥 |
| 4～5 | east 两次 | 乘外角经过南侧，到东档 2 |
| 6 | 走到 `(9,2,5)` | 下桥到东庭，取第二处必需光点 |
| 7 | 走到 `(8,2,5)` | 返回 east#1 外角；别把内端当成相同落点 |
| 8 | east 一次 | 外角到东档 3 的 `(8,2,3)` |
| 9 | west 一次 | 人已离开西低桥，把西桥调到档 3，由高台接回 |
| 10 | 走到 `(10,3,4)` | 从东外角跨高低错觉接口登 west#1 |
| 11 | west 一次 | 随高台到档 0 的灯塔一侧 |
| 12 | 走到 `(2,2,-3)` | 接上后方灯塔，点亮终点与三盏庭灯 |

第 9 步可以提前到第 3 步之后的任意安全位置，求解器也会给出这种等长解。不得强制玩家按表中的唯一操作时机。第一处移动光点也可在后续经过外角时收集，不能强制取光先后。

## 全收集标准解法（14 步）

采用已经独立校验的另一条最优路线，体现不同端点的用途：

| 步 | 动作 |
| --- | --- |
| 1～2 | 同主线，登低桥并 west 一次 |
| 3 | 走到 `(6,2,4)`，先登 east#0 内端 |
| 4 | west 一次，提前把西高台调到档 3 |
| 5 | east 一次，内端到 `(7,2,5)`，接上南庭 |
| 6 | 走到 `(7,2,6)`，收选做光点 |
| 7 | 走回 `(7,2,5)`，登内端 |
| 8 | east 一次，到东档 2 |
| 9 | 走到 `(9,2,5)`，经外角取移动光点，再取东庭必需光点 |
| 10 | 走到 `(8,2,5)`，改登外角，为返程选站位 |
| 11 | east 一次，外角到档 3 |
| 12 | 走到 `(10,3,4)`，登西高台 |
| 13 | west 一次 |
| 14 | 走到 `(2,2,-3)`，全收集点灯 |

选做不是在终点旁多点一格，也不要求整圈回转；要发现东桥第一次转动后的内端可以停靠南庭，取完再把返程站位换到外角。允许其他等长合法解，例如先取移动光点、在档 1 经内端走南庭后回外角。

## 干扰、反事实与行为测试

- 一直乘西低桥绕圈不能到高台，二者属于同一机关但不可在内部互通。
- 东庭拿光后站内端，在东档 3 会落到 `(7,2,3)`，仍距西高台两格；可以补走到外角恢复，不是死局。精简路线须在返程前选外角。
- 两处必需光点未齐不能点灯。南庭是可见选做支线，不能把它做成主线必经或直接收集。
- 反事实：分别禁用 west、east 的把手，均不可通关；只在测试副本把 west#1 改 solid 也无解；过滤站在对应机关上 operate 的动作后无解。
- 选做专属反事实：过滤 `east===1` 时路线含 east#0 的 walk，主线仍 12 步可解，全收集无解。这证明选做使用中途内端停靠；过滤只依赖 `applyAction(...).route`，不另写连接规则。
- 替换旧 `levels.test.ts` 两难专属坐标、west#2 遮挡和 15 步用例。保留核心 D14、撤销测试，为本稿加入外角／内端返程差异、两处必需光点、南庭、双把手和高台不可绕过的断言。
- 在主线第 8 步前后及第 11 步前后分别验证角色跟随、运动中拒绝行走、到位后撤销恢复；收光、点灯与三灯撤销一致。
