# 设计稿

> 已定稿。规则来源见 [decisions.md](decisions.md)；改动玩法前需征得用户同意。

## 一句话

路看似相连，就能走过去。

## 目标

- **类型**：等距视角的空间错觉解谜。体验方向参考《纪念碑谷》，玩法、关卡、美术全部原创。
- **体量**：9 关（序章加第 1～8 关），一遍 15～25 分钟。每关一个「原来如此」的瞬间。
- **平台**：电脑和手机浏览器，打开即玩。
- **体验关键词**：安静、温暖、好看、不挫败。

## 核心规则

### 看起来相邻，就是相邻

相机固定为等距正交视角，从 `(1, 1, 1)` 方向看向场景。沿这个方向平移的积木在屏幕上完全重合，所以每块积木有一个屏幕坐标 `(x - y, z - y)`。

- 两块**可行走路面**的屏幕坐标上下左右相邻（差为 `(±1, 0)` 或 `(0, ±1)`），就是相连的。
- 路面顶上压着任何积木时，不可行走。
- 只有标记为路面的积木参与寻路；结构积木（柱子、岛屿）只负责构图。

### 玩家做什么

1. 点击机关的金色把手，改变积木在屏幕上的排列。
2. 点击一块路面，小人自动沿最短路径走过去。
3. 走到终点的灯笼前，点亮它，通关。

## 机关

三种机关（D12），全部通过点击把手操作（D13）。

### 转盘

- 一组积木绕竖直轴，围着一个中心格旋转。中心格本身不动。
- 每点击一次把手，顺时针（从上往下看）转 90 度，动画 0.9 秒，缓入缓出。
- 档位 0～3 循环。
- 「换个角度」类关卡用大型转盘实现：整座建筑的大部分积木属于同一个转盘。
- 把手样式：金色转轮，装在转盘立柱的可见侧面上。

### 平移台

- 一组积木沿一个轴（`x`、`y` 或 `z`）在若干整数停靠位之间移动。
- 每点击一次把手，移动到下一个停靠位；到达最后一站后，下一次点击反向移动，像钟摆一样往返。
- 动画按距离计算，每格 0.45 秒，缓入缓出。
- 沿 `y` 轴就是升降台；沿 `x`、`z` 轴就是滑块，两者是同一种机关。
- 把手样式：金色拉杆，装在平移台的可见侧面上。

### 压板

- 压板是一块路面，表面有一圈金色边框。
- 小人**走到**压板上停下（不是路过）时，触发它绑定的机关动作一次：转盘转一档，或平移台去下一站。
- 每次重新站上去都会再触发一次；`once: true` 的压板只触发一次，之后变暗。
- 压板触发的机关如果正在运动，或小人站在该机关上，则本次不触发，压板闪一下提示。

### 共同约束

- 任意机关运动期间，不接受行走指令，也不接受其他机关的操作。
- 小人站在某个机关的积木上时，点击该机关的把手会让把手抖动 0.5 秒，并提示「站在上面可转不动」。
- 机关运动结束后，重新计算连通，再接受指令。

## 关卡

| 编号 | 关名 | 新内容 | 「原来如此」的瞬间 |
| --- | --- | --- | --- |
| 序章 | 启程 | 点击行走 | 只有普通的路，学会点哪走哪 |
| 1 | 看似 | 静态错觉连接 | 低处的路直接走上高塔顶端 |
| 2 | 转动 | 转盘 | 转动一座桥，让断开的两头看起来接上 |
| 3 | 升起 | 平移台（竖直） | 升起平台，它和远处的路对齐了 |
| 4 | 回望 | 大型转盘 | 转动整座塔，原本背面的路出现在眼前 |
| 5 | 先后 | 压板加转盘 | 先踩压板转动桥，再折返走过去 |
| 6 | 交错 | 平移台（水平）加大型转盘 | 两个机关的顺序决定路通向哪里 |
| 7 | 回环 | 压板加平移台 | 同一段路走两次，第二次通向别处 |
| 8 | 归来 | 全部机关 | 回到序章的地方，点亮所有灯笼，塔亮起 |

每关的具体要求：

- 解法步数（行走加操作）：序章到第 2 关不超过 4 步；第 3～5 关 4～8 步；第 6～8 关 6～12 步。
- 每关只引入一种新东西；教学关（第 1～4 关）不放干扰路线。
- 关卡制作规范、校验和解法格式见 [level-design.md](level-design.md)。

小样场景用作第 1 关和第 2 关的素材来源，不直接作为正式关卡。

## 界面流程

### 标题页

- 背景：序章场景，缓慢漂浮。
- 中央：Seemingly，下方小字「积木错位」。
- 按钮：「开始」进入第一个未通关的关卡（全部通关后进入第 8 关）；「选关」进入选关页。

### 选关页

- 9 张卡片，横向排布（手机端 3 列网格），显示编号、关名和灯笼状态。
- 已通关：灯笼亮。可玩但未通关：灯笼暗。未解锁：卡片半透明，不可点击。
- 解锁规则：通关第 N 关后解锁第 N+1 关；序章始终解锁。
- 左上角「返回」回到标题页。

### 游戏页

- 左上角：编号和关名，例如「2 · 转动」。
- 右上角：「重新开始」「选关」「静音」三个按钮。
- 序章和第 1、2 关底部显示操作提示；之后的关卡不显示。
- 键盘：`R` 重新开始，`Esc` 返回选关页。

### 通关

- 小人抵达终点，灯笼点亮，光点散开。
- 0.5 秒后顶部出现横幅：「抵达 · 关名」，按钮「下一关」。
- 第 8 关通关后不显示「下一关」，改为结尾画面：全部灯笼依次亮起，镜头不动，显示「谢谢游玩」和「回到标题」按钮。

## 反馈与手感

| 情况 | 反馈 |
| --- | --- |
| 悬停在路面上 | 顶板抬起 0.03、变亮，鼠标变成手形 |
| 点击可达路面 | 白色圆圈从目标处扩散后消失，小人出发 |
| 点击不可达路面 | 红色圆圈，顶部提示「看起来连不上，换个角度试试」1.8 秒，播放走不通音效 |
| 行走 | 每秒 2.6 格，每格一声轻脚步 |
| 机关运动 | 转盘 0.9 秒、平移台每格 0.45 秒，伴随低沉的机关声 |
| 站在机关上操作 | 把手抖动 0.5 秒，提示「站在上面可转不动」 |
| 抵达终点 | 灯笼点亮音效，光点散开，横幅出现 |

## 声音

全部用 Web Audio 合成（D20～D23）：

- **脚步**：极短的柔和噪声脉冲，音量很低，每走一格一次。
- **机关**：低频的木质「咔哒」声，转盘每转 90 度一次，平移台每移动一格一次。
- **走不通**：一个下行的柔和单音。
- **点亮灯笼**：明亮的三音上行琶音。
- **环境音**：两三个正弦波叠成的持续和弦，缓慢起伏，主音量的 10% 左右。
- 首次点击页面后才初始化音频；静音状态存入本地存储。
