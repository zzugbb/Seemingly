# 性能检查（T6.15）

检查日期：2026-10-23。基线：`622cce4` 加本任务静态积木合批。当前正式前四章十二关，以本节为准；文末保留首版九关历史数据，不能用它代表当前版本。

## 范围与方法

- 复用本地 Playwright 与缓存 Chromium 147，Apple M5 Pro / ANGLE Metal / WebGL2。桌面 1280×900 高画质、手机尺寸 375×667 低画质，像素比均为1，保留正常动态、云、光点与反馈。两组顺序执行，帧采样期间不并行运行构建或其他浏览器测试。
- 本轮前端测试技能所需 Browser 插件不可用，使用既有 Playwright 运行时，未安装依赖。测量在隔离5182开发源执行，不访问或预置用户5180存档。Vite临时测量配置不写入应用源码或生产构建。
- 每次进入关卡等待提示后台准备完成，再预热0.6秒、采集60个绘制帧；帧时间中位数与P95来自其中59个有效间隔。读取 Scene.onAfterRender 时的 WebGLRenderer.info.render.calls，包含高画质阴影 pass；低画质实测关闭阴影。
- 从新存档连续点击：桌面按十二关主线解法，手机按十二关全收集解法。坐标投影只用于点击，结果用共享规则只读校验，没有直接改角色／机关／进度。每次点击后截图刷新、等待模拟器空闲并核对结果；峰值覆盖开局、行走、机关运动、收光、点灯与完成卡出现后1.2秒。
- 手机仅为视口模拟，同样使用此电脑GPU，**不是中端手机或集成显卡笔记本真机验收**。帧时间是短窗口观察，不能据此宣称目标设备稳定60帧。全过程峰值覆盖所走解法，未穷举全部机关排列。
