# 第 5 关 · 叠庭

T6.12v4 教学更新：主线不再常驻显示下方参考实现中的hints。首次教学与收起条件以[设计稿](../design.md#游戏页)为准，已学状态跨撤销、重开、重进和刷新保留；仅改变操作说明，不改变本关谜题、标准解或提示按钮。

## 状态与目标

T6.12t 已实现；本稿由当前指定设计者在 T6.12v2 修订运动净空，取代旧坐标稿。正式 id 为 level-05、revision 3，第二章，courtyard 声景；内部 sample-01 复用本稿布局、保留独立 id 与免写主线存档的行为。**先乘升降台到侧廊，再把空台降下，让后方高台显露并接客。** 主线 11 步、全收集 12 步。

## 布局与调整

ferry 轴仍为 `(6,2,4)`，初始档0；#0 短端偏移 `(-1,0,0)`，#2 高台 `(3,1,2)`，#1 `(1,0,0)` 改为实心支座，不再呈现无用路面。六块折梁改在轴上方一格连接高台，完整偏移见参考实现。保留完整实心支架，避免旧低梁穿过升降台。

lift 原点 `(4,1,3)`，y轴、停靠 `[0,4]`，低位1／上位5；保留两块路面和中央下支撑，移除向侧面伸出的下支撑。人必须从侧翼登台。三格玫瑰色静态侧廊为 `(0,1,-2)`、`(1,1,-2)`、`(1,1,-1)`，第一格有必需光点；选做西台为 `(-2,1,-1)`。侧廊通过投影接驳上层侧翼，人在侧廊降空台后才看得见 ferry#2。ferry#0 有另一处必需光点。

起点岛扩为 x[-3,3]、z[-2,3]、y=-1，容纳西台和侧廊支撑。转轮支座沿视线平移三格到 `(11,3,9)`，保持屏幕位置且露出把手；lift 拉杆仍在 `(6,0,6)` z 面。终点岛地面为y=1，柱从2到4、顶面 `(12,5,8)`，让出低位桥的扫掠空间。完整清单以参考实现为准。

## 主线标准解法（11 步）

| 步 | 动作 |
| --- | --- |
| 1 | `(5,2,4)`，登短端取必需光点 |
| 2 | `(3,1,3)`，登低位升降台侧翼 |
| 3～4 | ferry 两次，预先把高台调来 |
| 5 | lift 一次，乘侧翼升到5 |
| 6 | `(0,1,-2)`，走到静态侧廊收必需光点 |
| 7 | lift 一次，降低空台让 ferry#2 显露 |
| 8 | `(3,3,2)`，登高台 |
| 9～10 | ferry 两次 |
| 11 | `(12,5,8)`，点灯与庭院回应 |

## 全收集（12 步）

标准解第5步升到上层后，先走 `(-2,1,-1)` 取选做，再继续第6～11步。保留跨次累计：12步全收集与11步最少步数可分两次获得。

## 干扰、指标与验收

停在升降台上只会上下往返，不能替代离台后降空台；ferry 未在档2时降台不形成正确接驳，仍可继续调整。分别禁用 lift／ferry 把手均无解；降空台前 ferry#2 被遮挡、降下后可进入，撤销恢复遮挡。收光、升降乘坐、登高台、点灯和撤销都须验证。

| 最少／全收集 | 状态／死局 | 随机30步（种子20261016，500次） | 标准解错觉／取舍 |
| --- | --- | --- | --- |
| 11／12 | 504／0 | 0.2% | 6／2 |

旧版512状态中的无用登台状态随实心支座取消；没有死局，原 targets 不变。正式HUD、评价、下一关和三灯回应保留；内部样段仍只由 `?sample=1` 访问，与主线存档隔离。

## 运动与角色净空（T6.12v2）

仅修复实体结构与运动净空，固定镜头、屏幕连通、遮挡断路和乘坐规则不变，不加入三维行走碰撞。既有主线发现、必需／选做光点职责与 targets 保留。保持当前 revision，保留玩家已获评价；本轮没有新增评价条件或提高最少步数。

机关运动时角色在 0.12 秒内轻微收身到原高度的 94%，足底不动，到位后恢复；正常站立与呼吸不变，剪影跟随同一姿态。此姿态最多让出帽尖附近 0.06 格，不能掩盖身体与建筑相撞。净空检测同时检查收身开始、运动中、到位恢复站立，不能从第一帧就假定角色已收身。具体检测尺寸、轴承例外与采样限制见 [运动净空](../motion-clearance.md)。

验收须包括所有可达机关组合、合法站位的运动采样、主线和全收集、错误操作后的恢复、乘坐及撤销，以及桌面／手机实际点击和中间帧截图。规则、targets、音频和存档实现不改；T6.12 仍待用户整体试玩确认。

## 完整参考实现

```ts
import { defineLevel } from './builders'
import type { Vec3 } from './types'
export default defineLevel({
  id: 'level-05',
  title: '叠庭',
  chapter: 2,
  revision: 3,
  soundtrack: 'courtyard',
  hints: ['转轮转动桥臂，拉杆升降平台'],
  build: (b) => {
    b.island({ x: [-3, 3], z: [-2, 3], y: -1, depth: 2.5 })
    for (const x of [0, 1]) b.path([x, 0, 2], 'terracotta')
    b.island({ x: [4, 9], z: [0, 8], y: -1, depth: 3.5 })
    b.column({ x: 6, z: 4, from: 0, to: 2 }, 'teal')
    for (const p of [
      [6, 0, 5],
      [6, 0, 6],
      [7, 0, 6],
      [11, 3, 9],
    ] as Vec3[])
      b.solid(p, 'teal')
    b.rotator({
      id: 'ferry',
      pivot: [6, 2, 4],
      blocks: [
        { offset: [-1, 0, 0] },
        { offset: [1, 0, 0], kind: 'solid', color: 'teal' },
        { offset: [3, 1, 2] },
        ...(
          [
            [1, 1, 0],
            [2, 1, 0],
            [3, 1, 0],
            [4, 1, 0],
            [4, 1, 1],
            [4, 1, 2],
          ] as Vec3[]
        ).map((offset) => ({
          offset,
          kind: 'solid' as const,
          color: 'teal' as const,
        })),
      ],
      handle: { block: [11, 3, 9], face: 'z' },
    })
    b.orb({ mechanism: 'ferry', block: 0 })
    b.mover({
      id: 'lift',
      origin: [4, 1, 3],
      axis: 'y',
      stops: [0, 4],
      blocks: [{ offset: [0, 0, 0] }, { offset: [-1, 0, 0] }, { offset: [0, -1, 0], kind: 'solid', color: 'teal' }],
      handle: { block: [6, 0, 6], face: 'z' },
    })
    for (const p of [
      [0, 1, -2],
      [1, 1, -2],
      [1, 1, -1],
    ] as Vec3[]) {
      b.solid([p[0], 0, p[2]], 'rose')
      b.path(p, 'rose')
    }
    b.orb({ tile: [0, 1, -2] })
    b.solid([-2, 0, -1], 'terracotta')
    b.path([-2, 1, -1], 'terracotta')
    b.orb({ tile: [-2, 1, -1], optional: true })
    b.island({ x: [10, 12], z: [6, 8], y: 1, depth: 4 })
    b.column({ x: 12, z: 8, from: 2, to: 4 }, 'rose')
    b.path([12, 5, 8], 'rose')
    b.tree([-1, -1, 3])
    b.flower([7, -1, 8])
    b.window({ pos: [12, 2, 8], face: 'x' })
    b.lamp([0, -1, 3])
    b.lamp([8, -1, 7])
    b.lamp([10, 1, 8])
    b.start([0, 0, 2])
    b.goal([12, 5, 8])
  },
  solution: [
    { type: 'walk', to: [5, 2, 4] },
    { type: 'walk', to: [3, 1, 3] },
    { type: 'operate', mechanism: 'ferry' },
    { type: 'operate', mechanism: 'ferry' },
    { type: 'operate', mechanism: 'lift' },
    { type: 'walk', to: [0, 1, -2] },
    { type: 'operate', mechanism: 'lift' },
    { type: 'walk', to: [3, 3, 2] },
    { type: 'operate', mechanism: 'ferry' },
    { type: 'operate', mechanism: 'ferry' },
    { type: 'walk', to: [12, 5, 8] },
  ],
})
```
