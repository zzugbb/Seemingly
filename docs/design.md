# 游戏设计

## 一句话

路看似相连，就能走过去。玩家在固定等距视角下，转动或移动积木，让投影上的道路接起来，为小人拼出通往灯笼的路线。

体验目标是空间发现、操作后的因果反馈和有余地的试错；思考没有倒计时，关卡难度来自动作依赖与取舍。当前五章十五主线、五挑战、结局和音乐均已获用户试玩确认。

## 核心规则

### 看起来相邻，就是相邻

积木世界坐标 `(x,y,z)` 映射到屏幕坐标 `(a,b)=(x-y,z-y)`，上下左右相邻的路面相连，斜对角不算。不增加真实高度差或距离限制。相机固定为 `(1,1,1)` 方向的正交视角，不能旋转或缩放。

点击可达路面自动寻路，走过整条路线算一步。路面被积木顶压或其顶面中心被前景建筑遮挡时不能进入；已站在被遮挡格上仍可离开。门、箱和巡逻占位由同一规则层处理，角色剪影只帮助定位，不开放新路径。

### 机关、箱子与巡逻

| 元素 | 行为与约束 |
| --- | --- |
| 转盘 | 点击把手转90度，桥上人物和箱随机关移动 |
| 平移台 | 点击拉杆移至下一停靠位，端点改变往返方向；支持水平或竖直运动 |
| 触发压板 | 人物停住后触发一次，路过不触发；可设置一次性 |
| 按住压板 | 人物、箱或巡逻者静止压住时打开对应按住门，离开后恢复 |
| 切换门 | 把手或联动切换；门内被占用时不关门 |
| 按住门 | 只由按住压板控制；寻路按人物已离开自身压板求值，门内仍有占位保护 |
| 联动 | 一次操作可同步驱动其他机关，只做一层，不递归；reverse只对转盘反向有效 |
| 无把手机关 | 只能通过联动或压板驱动，不能直接点击 |
| 限次把手 | 每次成功操作消耗一次，圆点显示余量；用完可撤销恢复 |
| 积木箱 | 人物与箱屏幕相邻时，点箱沿该方向推一格；可跨错觉连接并随机关运输，不能拉箱 |
| 单向格 | 只允许从箭头方向进入，不限制离开方向 |
| 巡逻者 | 每个完整合法动作后前进一步，受阻等待，可压住按住板；遵守单向和遮挡，不收光、不触发普通压板 |

机关运动时拒绝行走，不排队；行走中可重新选择目标且不多计步。所有机关都可远程点把手，不能用额外的靠近限制强迫标准路线。

## 光点与灯笼

每关终点是一盏灯笼。必需光点集齐后抵达即可点亮；选做光点有细环，不影响主线通关。路过光点即收集，机关上的光点随机关运动。必需不足时靠近终点只提示还差数量，不结束本局。

第一章三关通关后解锁挑战一；第二至五章三关都获得全收集历史评价后，分别解锁对应挑战。挑战独立于主线结局。

## 撤销、步数、评价与提示

一次行走、推动或机关操作各算一步。无限撤销完整动作，行走中可撤销，机关运动时先等到位；重开清空本局，历史成绩保留。

每关三个条件独立累计：抵达、全收集、步数不超过求解器的最少步数。二十关共六十项历史评价，三项可以分局补齐，较差重玩不覆盖已有评价。最少步数评价还要求本局未使用主动提示。

提示在后台 Worker 建立策略，点击后高亮最优下一步；无获胜策略时建议撤销。实际得到提示或无解反馈才计 usedHint。线程创建／运行失败只显示“提示暂时不可用，请稍后再试”，不影响评价或正常游玩。

## 章节与关卡

| 章节 | 主线 | 体验递进 |
| --- | --- | --- |
| 看似 | 启程、转动、随行 | 投影连接、主动改变连接、人物乘坐 |
| 转动 | 换乘、叠庭、回环 | 中转、让出位置显露通路、双桥去返接力 |
| 升起 | 停靠、联动、牵引 | 多站运输、共享远桥控制、调用后恢复归路 |
| 推动 | 推动、越界、重量 | 运箱与返程、一箱分阶段压门、有限运输中的重量规划 |
| 遮挡 | 留步、相守、归来 | 巡逻动态压力、箱与巡逻共同守门、最终交换职责 |

五个挑战依次为回针、分岸、逆织、递位、相托，分别深化母章能力，不是必须线性通关的第二条主线。前三挑战无死局，后两关保留后期阶段错误及撤销恢复；不以死局数量宣称更难。

每关的坐标、最优解、全收集解、关键依赖与恢复路线以[正式关卡设计](levels/README.md)为准。本文不重复谜题数据。

## 界面流程

### 标题页

“积木错位”为主名，Seemingly作辅助品牌；真实第一关初始建筑与文字分区。主线没有完成记录时显示“开始旅程”，未全通时“继续旅程”前往首个尚未抵达关，从该关开局开始；全通后“重访旅程”进入选关，不承诺恢复未完成棋盘。

有进度时显示“主线 N/15 · 挑战 M/5”和“已获评价 X/60”。全主线抵达说明只称主线完成；六十项齐全才显示“全部关卡与评价已完成”。始终保留选关和静音，主线全通后增加旅程成绩。

桌面至少960px为左文右建筑，最大宽1280px；窄屏按品牌、标题、短句、建筑、进度、主按钮、次入口纵排，两个次入口同排。按钮高48px，手机左右24px并叠加安全区；小屏或大字体允许整页纵向滚动。相机算法不为入口单独改变。

### 选关页

一按进入关卡，按章显示十五主线与五挑战；卡片含编号、关名、主题、评价数量和具名三项评价，最少步数并入评价行。已完成不再重复“已抵达”文字；下一站、可探索或实际锁定原因按存档导出。

解锁只调用现有 isUnlocked，记录缺口不能凭最大关号补解锁或删除后续成绩。锁定卡禁用但仍展示有效历史。

桌面三列卡片，右侧最多一个真实初始建筑预览；hover／键盘focus切换已解锁关的预览，不改进度、音乐或关卡状态。窄屏两列，不挂载预览画布。内容纵向滚动，锁定说明不截断，触控目标至少44px。

### 游戏页

场景占主视觉，HUD展示关名、步数与光点，常用撤销／提示直接可点；手机把重开、选关和静音放进菜单。`Z`撤销，`H`提示，`R`重开，`Esc`返回选关。

首次能力教学一次一句，完成对应真实动作后收起，记忆跨撤销／重开／重进／刷新保持；挑战不重复教学。空闲时不保留空白提示栏。运动／到位、缺必需光点、主动提示与失败反馈仍临时显示，不直接给解法。

### 通关与结局

完成卡只展示本次评价、本次步数／最少步数、必要提示使用标记与解锁结果，提供下一关／回选关及重试。历史评价留给选关与成绩卡，不重复堆叠。

主线按顺序前进；挑战只在下一编号已解锁时提供下一关，末关或下一关锁定则回选关，不跳过缺口。补完任意最后一个挑战时，本次卡显示“全部挑战已抵达”，重玩不重复。

第九、十二关点灯后留2.2秒观看庭院回应，再出现结果；减少动态为0.2秒。第十五关终点先亮，其余灯每隔0.45秒点亮，全部亮后0.6秒照亮塔，再过0.9秒出现“谢谢游玩”、旅程成绩和返回标题。撤销／重开／退出仍可用并取消旧演出；挑战不进入此结局。

## 旅程成绩卡

主线全通后，从标题、选关、主线结局或正式关完成卡主动打开。竖版图片含归来建筑、主线／挑战抵达数、历史评价总数和三项数量，三个里程碑分别为“主线关卡已全部抵达”“全部关卡已抵达”“全部关卡与评价已完成”。不增加总分、排名、用时或在线系统。

预览可上下滑动，保存PNG使用同一完整图片，不把按钮和浏览器边框画进去。支持文件分享的浏览器提供系统分享；取消静默，失败或不支持时保留图片与下载。手机可长按或截图，下载通常进入下载列表，不能承诺直接写相册。

关闭／Esc返回原画面并恢复入口焦点，快捷键不穿透。生成失败可重试；模块网络加载失败仅说明检查网络或刷新，不使游戏空白、不自动刷新或修改历史。图片由当前代码在本地生成。

## 反馈与手感

| 情况 | 表现 |
| --- | --- |
| 点击可达路面 | 白色目标圈加深色外缘，保留到抵达后淡出 |
| 路面未连通 | 临时说明“这里还没连通”，有机关时建议调整建筑，不暗示旋转镜头 |
| 操作把手 | 最多缩小8%，0.18秒恢复；对应运动结构提亮，到位0.9秒淡回 |
| 正在移动／到位 | 底部短句只说明当前状态，不判断是否正确 |
| 缺必需光点 | 显示缺少数量，灯芯短暂闪烁 |
| 推不动／把手用尽／单向受阻 | 短反馈与既有抖动，不计成功动作 |
| 收光／点灯／新增评价 | 相应视觉和合成音，按真实事件触发 |
| 角色被挡 | 只显示被遮挡片段的定位剪影，不开放新路面 |

减少动态效果保持稳定色差和必要文字，不增加摇摆、扩散或粒子；撤销／重开清理临时反馈。尺寸与配色见[视觉规范](#视觉规范)。

## 音乐

五章均使用原创courtyard主题、合成键盘、轻拨弦、低电平铺底和混响，保留有留白的旋律。前四章当前混音、第五章及挑战慢速声音均已由用户确认；电平测试不替代试听，不重新调音。

| 章节 | 调式 | 速度 | 循环 |
| --- | --- | --- | --- |
| 看似 | C大调 | 80 BPM | 128拍／96秒 |
| 转动 | A小调 | 80 BPM | 128拍／96秒 |
| 升起 | D多利亚 | 88 BPM | 128拍／约87.273秒 |
| 推动 | E♭大调 | 96 BPM | 128拍／80秒 |
| 遮挡 | F利底亚 | 84 BPM | 128拍／约91.429秒 |

第三章以左右问答和B自然音打开空间；第四章以弱拍、上行和重音推进，尾句回E♭；第五章逐步留出相互守候的空间，结局收束到F。精确谱面在 theory.ts；第三至五章另有设计基准 [chapter-scores.mjs](levels/chapter-scores.mjs) 与 [chapter-5-score.mjs](levels/chapter-5-score.mjs)，由正式校验器比对，不作为站点资源导入。

背景只按真实收光和通关进入 explore／gather／ready／complete，不按空转次数、连接正确性、箱位或求解结果变化。普通必需、最后必需、选做、点灯与新增历史评价使用不同反馈，最后必需不叠播普通收光声，重复评价不重复奖励。

第九、十二关点灯后2.1秒接章节四音；第十五关终点进入F铺底，塔亮才接塔音序，装饰灯不逐灯发成功音。所有延后声音都可由撤销、重开、静音或退出取消，不带入下一局。

混音固定为主0.28、音乐0.18、反馈0.75、混响发送0.35，主题层3.3、旋律包络0.5、铺底0.08；当前主旋律与铺底180Hz高通。关键反馈35ms进入背景让位，按事件持续后恢复，脚步／巡逻不反复压低。最多12音源，其中音乐8个，反馈优先。

挑战沿母章整套谱面按90%速度播放，音符、时值、和弦、脉冲、循环和暂停／恢复用同一时钟；反馈速度与音量不改。首次交互解锁，静音停止输出与调度，恢复不补播旧效果，同章时钟连续，跨章按既有淡化切换。

## 不做的事

产品范围与固定约束以[项目决策](decisions.md)为准；不加入新机关、镜头、外部素材或在线功能。

## 视觉规范

暖色、低饱和、圆角积木与黄昏渐变，保留空间和文字留白。画面由代码生成，不引入模型、贴图、外部字体或音频素材。配色在[palette.ts](../src/game/render/palette.ts)，共享几何／材质在[materials.ts](../src/game/render/materials.ts)，实体尺寸与角色包络在[shapes.ts](../src/game/core/shapes.ts)。不得在渲染组件另写色值或每帧新建材质。

| 对象 | 必须保持的辨识方式 |
| --- | --- |
| 路面与结构 | 路面统一浅顶板，和无顶板的实心结构区分；暖陶土、沙色、玫瑰粉构成建筑 |
| 机关 | 青绿／浅青绿表示可移动结构，金色把手可远程点击；转轮与拉杆使用不同造型 |
| 压板与门 | 单框触发板、双框按住板；按住门中央的金点与压板呼应，门打开沉入顶板以下 |
| 箱与巡逻者 | cream箱体小于路面，角部金饰表示可推；巡逻者为rose圆球和深色眼睛，不用交互金色或机关青绿 |
| 光点与灯笼 | 必需光点为金球，选做加细环；灯芯随必需收光从plum变glow，点亮后暖光回应 |
| 角色 | 深色身体、浅色头部、陶土帽子；行走／转身／呼吸轻微，脚底贴路面。被挡部分使用cream、0.7不透明度剪影，不改变可进入格 |
| 评价 | 内联SVG配具名文字、勾／短横；已获深色描边与淡金底，未获仍可读，不靠悬停解释 |
| 界面 | 系统字体（苹方／冬青黑体／微软雅黑）、深色正文、暖白底与圆角胶囊，按钮触控区域至少44×44px并避让安全区 |

积木0.98、圆角0.07；顶板0.84见方、厚0.12，悬停抬起0.03；岩层逐层收窄，层高0.62。装饰只放在岛屿地面，不妨碍路面和把手辨识。固定取景、主光与高／低画质阴影保持原实现，不以新镜头或新增粒子层替代信息表达。

机关运动时角色轻微收身，到位恢复；同一变换用于实体和剪影，边界见[运动净空](level-design.md#运动净空)。灯笼光粒使用实例化，高／低10／5颗，减少动态为0；必要的动作位移仍保留。

成绩卡沿用同一暖色纸底与深梅色文字，中文标题和完成阶段在上，归来建筑居中，成绩与站点地址在下；颜色从palette的journey字段读取。PNG为完整实底矩形，预览圆角不写进导出图，不包含按钮或浏览器边框。
