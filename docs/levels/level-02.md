## 教学点与原来如此

第一章「看似」。在第一关已经知道投影相邻可以走的基础上，第一次操作金色转轮，亲手改变连接。**转动会接通一边，也会断开另一边；先站到建筑内部，再改变出口。** 只引入一个转盘，不要求理解乘坐、换乘、升降或遮挡。

中央粉色带顶板的平台是静态落脚点。主线可站在这里操作，无需乘坐；玩家若站在桥臂上完成同样三步也合法，不得为了教学而禁用 D14。第三关才要求必须乘坐。

## 屏幕草图

`(a,b)=(x-y,z-y)`，数字为高度，`o` 为必需光点。初始转盘档 0。

```text
             (2,0) 0G 灯笼
             (2,1) 空，档 1 时桥臂抵达
(0,2) 0@ — (1,2) 1桥臂 — (2,2) 1o静台 — (3,2) 1桥臂
             (2,3) 空，档 1 时另一桥臂抵达
```

桥臂屏幕落点：#0 为 `(1,2)→(2,3)→(3,2)→(2,1)`，#1 为 `(3,2)→(2,1)→(1,2)→(2,3)`。灯笼始终在 `(2,0)`。中心静台不旋转。

## 积木、机关与目标清单

- 两座地面基座：入口 `x[-1,1],z[1,3],y=-1,depth=2`，主建筑 `x[2,5],z[0,4],y=-1,depth=2.5`，不可合并到重叠。
- 起点路面 `(0,0,2)`、中央路面 `(3,1,3)`、灯笼路面 `(2,0,0)`；中心柱 `(3,0,3)`，控制底座 `(4,0,4)` 均实心。
- `bridge` 转盘：中心 `(3,1,3)`、档 0、两路面偏移 `(-1,0,0)`、`(1,0,0)`；把手 `(4,0,4)` 的 z 面，无联动、不限次数。
- 仅一处必需光点 `(3,1,3)`，无选做。无箱子、门、压板、单向格、巡逻者。
- 树 `(-1,-1,3)`、花 `(5,-1,0)`、中心柱 z 面窗 `(3,0,3)`；完整坐标以参考实现为准。

## 标准解法与干扰路线

| 步 | 动作 | 用意 |
| --- | --- | --- |
| 1 | 走到 `(3,1,3)` | 经左桥臂进入中心静台，取光 |
| 2 | bridge 一次 | 站在静台上把桥转向灯笼 |
| 3 | 走到 `(2,0,0)` | 经北侧桥臂跨到灯笼 |

开局先点灯笼应为不可达。先在入口转桥会断开入口，可继续转回或撤销；没有永久死局。不得补上 `(2,1)` 的静态路面，否则操作失去意义。不得把中心改成实心，否则将强制乘坐、改变本关教学目标。

## 指标与难度目标

2026-10-21 用现有规则、求解器、模拟器及校验器验证；随机种子 20261016，500 次，30 步。

| 最少 / 全收集 | 状态 / 死局 | 随机通关率 | 错觉 / 取舍 |
| --- | --- | --- | --- |
| 3 / 3 | 34 / 0 | 87.8% | 2 / 1 |

第一章允许短教学和较高随机通关率，不借提高步数或藏光点制造难度。禁止把手后无解；过滤「站在机关上时操作」后仍有解，证明本关未强制乘坐。

## 实现验收

- 使用参考实现；`revision: 3` 仅使旧第二关评价失效，不清除其他关进度和静音。
- 测试标准三步、开局灯笼不可达、先转桥可恢复、收光撤销、禁用把手无解，以及中心静台路线无须乘坐。
- 桌面 1280×720、手机 375×667 检查开局、转动中、到位后和点灯。把手、中心顶板、两桥臂、光点、灯笼均可辨；中心和桥臂不会被误认为同一个运动组件。
- T6.12v4 起转轮说明只作首次教学，到位后收起，不添加「先走中心再转」等解法文字；主动请求提示仍由 Worker 给下一步。
- 第一章 C 大调 courtyard 声景、既有评价与解锁不变，沿用 T6.12p 的操作反馈。通过四项提交检查后，才把 T6.12q 勾选，并将本稿状态标为已实现。

```ts
import { defineLevel } from './builders'

export default defineLevel({
  id: 'level-02',
  title: '转动',
  chapter: 1,
  revision: 3,
  soundtrack: 'courtyard',
  hints: ['点击金色转轮，观察路面怎样连接'],
  build: (b) => {
    b.island({ x: [-1, 1], z: [1, 3], y: -1, depth: 2 })
    b.path([0, 0, 2], 'terracotta')
    b.island({ x: [2, 5], z: [0, 4], y: -1, depth: 2.5 })
    b.column({ x: 3, z: 3, from: 0, to: 0 }, 'rose')
    b.path([3, 1, 3], 'rose')
    b.orb({ tile: [3, 1, 3] })
    b.solid([4, 0, 4], 'terracotta')
    b.rotator({
      id: 'bridge',
      pivot: [3, 1, 3],
      blocks: [{ offset: [-1, 0, 0] }, { offset: [1, 0, 0] }],
      handle: { block: [4, 0, 4], face: 'z' },
    })
    b.path([2, 0, 0], 'terracotta')
    b.tree([-1, -1, 3])
    b.flower([5, -1, 0])
    b.window({ pos: [3, 0, 3], face: 'z' })
    b.start([0, 0, 2])
    b.goal([2, 0, 0])
  },
  solution: [
    { type: 'walk', to: [3, 1, 3] },
    { type: 'operate', mechanism: 'bridge' },
    { type: 'walk', to: [2, 0, 0] },
  ],
})
```
