# 第 3 关 · 错位

## 关名、章节、教学点

- 第一章「看似」，第 3 关（章末）。
- 教学点：多处错觉连接组成的环线；干扰岔路；路过自动收集光点。

## 原来如此

- 起点北边的岔路，尽头只和远处的路斜对角挨着，看上去差一点就接上，其实走不通。光点放在这条岔路尽头，必须专门进去拿。
- 沿三处错觉连接，可以从低处上到塔顶，再下到中层，然后爬上第二座塔，最后绕到灯笼。
- 中层步道上的光点恰好在去第二座塔的路上，直接点远处的塔顶，路过时就会顺手收集。

## 屏幕草图

```text
    0   0
  0   0   0o
0@
  0       1
    0   3   1
      3       1o
            4   2
              4o  2G
```

右上角的 `0o` 是干扰岔路的尽头，和它右下方的 `1`（中层步道起点）只是斜对角，不相连。

## 积木清单

- 西岛：地面 `x -1～3、z -2～3`。陶土步道（高度 0）：主线 `(0,0,2)` 起点、`(1,0,2)`、`(2,0,2)`；干扰岔路 `(0,0,1)`、`(0,0,0)`、`(1,0,0)`、`(1,0,-1)`、`(2,0,-1)`。
- 第一座塔：地面 `x 5～7、z 3～6`（岩层深 4）；粉色柱子 `(6,0..2,5)`、`(6,0..2,4)`；塔顶（高度 3）`(6,3,5)`、`(6,3,4)`。
- 中层步道：地面 `x 4～7、z 0～1`；陶土垫块 `(4,0,1)`、`(5,0,1)`、`(6,0,1)`，步道（高度 1）`(4,1,1)`、`(5,1,1)`、`(6,1,1)`。
- 灯笼平台：地面 `x 8～10、z 1～3`；沙色柱 `(8,0..1,2)`、`(9,0..1,2)`；奶油色路面（高度 2）`(8,2,2)`、`(9,2,2)`，`(9,2,2)` 是终点。
- 第二座塔：地面 `x 8～11、z 4～6`（岩层深 5）；粉色柱子 `(9,0..3,5)`、`(10,0..3,5)`；塔顶（高度 4）`(9,4,5)`、`(10,4,5)`。

## 机关清单

无。

## 光点清单

| 编号 | 位置 | 类型 |
| --- | --- | --- |
| orb-0 | `(2,0,-1)` 干扰岔路尽头 | 必需 |
| orb-1 | `(6,1,1)` 中层步道末端 | 必需 |
| orb-2 | `(10,4,5)` 第二座塔顶 | 必需 |

## 其他元素

无。

## 标准解法

1. 走到 `(2,0,-1)`：进干扰岔路拿光点。
2. 走到 `(10,4,5)`：经第一座塔顶下到中层步道（路过拿到 orb-1），再上第二座塔顶拿 orb-2。
3. 走到 `(9,2,2)`：从第二座塔顶沿错觉连接下到灯笼平台。

## 干扰与陷阱

- 干扰岔路尽头看起来几乎接上中层步道，玩家可能以为能从这里抄近路，其实不行。
- 如果先点 orb-1 再点 orb-2，会多花一步，拿不到「步数」评价。

## 参考实现

```ts
import { defineLevel } from './builders'

export default defineLevel({
  id: 'level-03',
  title: '错位',
  chapter: 1,
  build: (b) => {
    b.island({ x: [-1, 3], z: [-2, 3], y: -1 })
    for (const pos of [
      [0, 0, 2],
      [1, 0, 2],
      [2, 0, 2],
      [0, 0, 1],
      [0, 0, 0],
      [1, 0, 0],
      [1, 0, -1],
      [2, 0, -1],
    ] as const)
      b.path([...pos], 'terracotta')
    b.orb({ tile: [2, 0, -1] })

    b.island({ x: [5, 7], z: [3, 6], y: -1, depth: 4 })
    b.column({ x: 6, z: 5, from: 0, to: 2 }, 'rose')
    b.column({ x: 6, z: 4, from: 0, to: 2 }, 'rose')
    b.path([6, 3, 5], 'rose')
    b.path([6, 3, 4], 'rose')

    b.island({ x: [4, 7], z: [0, 1], y: -1 })
    for (const x of [4, 5, 6]) {
      b.solid([x, 0, 1], 'terracotta')
      b.path([x, 1, 1], 'terracotta')
    }
    b.orb({ tile: [6, 1, 1] })

    b.island({ x: [8, 10], z: [1, 3], y: -1 })
    for (const x of [8, 9]) {
      b.column({ x, z: 2, from: 0, to: 1 }, 'sand')
      b.path([x, 2, 2], 'cream')
    }

    b.island({ x: [8, 11], z: [4, 6], y: -1, depth: 5 })
    for (const x of [9, 10]) {
      b.column({ x, z: 5, from: 0, to: 3 }, 'rose')
      b.path([x, 4, 5], 'rose')
    }
    b.orb({ tile: [10, 4, 5] })

    b.start([0, 0, 2])
    b.goal([9, 2, 2])
  },
  solution: [
    { type: 'walk', to: [2, 0, -1] },
    { type: 'walk', to: [10, 4, 5] },
    { type: 'walk', to: [9, 2, 2] },
  ],
})
```
