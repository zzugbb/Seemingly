# 第 5 关 · 乘风

## T6.12i 校准

用户授权持续完成前六关校准。第五关正式教学乘坐与单转盘换乘：短臂与长臂用途不同，需要借静态落脚点换乘，不能坐同一条桥臂一路到灯笼。主线 8 步，选做 12 步；第六关已认可版本保持不变。

## 教学点与原来如此

- 短臂带着必需光点，长臂才能在东侧接上高平台和灯笼。
- 桥中心是实心，不能从短臂穿过中心走到长臂；先随短臂到南侧，下桥等长臂转来，再登船。
- 选做的北台不只是多走一格，也是另一处中转站；选择北侧路线，可以在拿选做光点的同时换到长臂。

## 屏幕草图

`(a,b)=(x-y,z-y)`；中心为 `(4,2)`、高度 2，实心。

```text

入口末端 (2,2) / 高度 0

北台选做 (4,0) / 高度 1
灯笼塔   (7,2) / 高度 5

短臂，高度 2：档 0 (3,2) → 1 (4,3) → 2 (5,2) → 3 (4,1)
长臂登船位，高度 2：档 0 (5,2) → 1 (4,1) → 2 (3,2) → 3 (4,3)
长臂高平台，高度 3：档 0 (6,2) → 1 (4,-2) → 2 (0,0) → 3 (2,4)
```

只有档 0 时，长臂登船位与高平台在画面接上，继而连接灯笼塔。其余档位应先站在长臂登船位等待转到东侧，不能沿实心折梁走上高平台。南侧落脚点只有短臂转来后才可从入口抵达。

## 积木清单

- 西岛 `x -1～3、z 1～3、y=-1、深度 2.5`；陶土路 `(0,0,2)`、`(1,0,2)`、`(2,0,2)`。
- 中央庭院 `x 4～9、z 0～8、y=-1、深度 3.5`；青绿实心轴 `(6,0～2,4)`，顶部不是路面。
- 控制底座青绿实心 `(6,0,5)`、`(6,0,6)`、`(7,0,6)`、`(8,0,6)`。
- 南侧陶土落脚点 `(4,1,4)`，下方 `(4,0,4)`；北台 `(5,1,1)`，下方 `(5,0,1)`。
- 灯笼岛 `x 11～13、z 6～8、y=-1、深度 5`，粉色塔柱 `(12,0～4,7)`，路面 `(12,5,7)`。
- 起点 `(0,0,2)`，终点 `(12,5,7)`。

## 机关清单

一个 `ferry` 转盘，中心 `(6,2,4)`，初始档 0，无联动、无限次顺时针，把手在 `(8,0,6)` 的 z 面。

| 下标 | 偏移 | 类型 |
| --- | --- | --- |
| 0 | `(-1,0,0)` | 短臂路面，必需光点随它移动 |
| 1 | `(1,0,0)` | 长臂登船位路面 |
| 2 | `(3,1,1)` | 长臂高平台路面 |
| 3～7 | `(1,-1,0)`、`(1,-1,1)`、`(2,-1,1)`、`(3,-1,1)`、`(3,0,1)` | 青绿实心折梁，不可行走 |

## 光点与其他元素

- `orb-0`：`ferry#0` 短臂，必需，开局在 `(5,2,4)`。
- `orb-1`：北台 `(5,1,1)`，选做。
- 无箱子、门、压板、单向格或巡逻者。
- 三处装饰：树 `(-1,-1,3)`、花 `(7,-1,8)`、灯笼塔 x 面窗 `(12,2,7)`。

## 主线标准解法

1. 走到 `(5,2,4)`，登短臂并收集必需光点。
2. ferry 一次，短臂带人到南侧。
3. 走到 `(4,1,4)`，下桥留在南侧静态落脚点。
4～5. ferry 两次，让长臂登船位转到南侧。
6. 走到 `(6,2,5)`，登 `ferry#1`。
7. ferry 一次，长臂带人到东侧，高平台接上。
8. 走到 `(12,5,7)`，经过 `ferry#2` 高平台，点亮灯笼。

## 全收集标准解法

| 步 | 动作 |
| --- | --- |
| 1 | 走到 `(5,2,4)`，登短臂并取必需光点 |
| 2～4 | ferry 三次，留在短臂绕到北侧 |
| 5 | 走到 `(5,1,1)`，取选做光点并留在北台 |
| 6～7 | ferry 两次，让长臂登船位来到北侧 |
| 8 | 走到 `(6,2,3)`，登 `ferry#1` |
| 9～11 | ferry 三次，随长臂到东侧 |
| 12 | 经高平台走到 `(12,5,7)` 点灯 |

北侧路线完成选做时也完成换乘，不要求先走主线南侧再额外绕完整一圈。

## 干扰与陷阱

- 只坐短臂转到东侧会停在长臂登船位的同一投影位置，但此时长臂在另一边，短臂不能跨过一格空隙接高平台；必须先离桥换臂。
- 中心与折梁是实心，不能当作走廊。
- 在南台或北台转错一档只会暂时断路，可继续转回或撤销，无永久死局。
- 北台光点开局可见；南侧落脚位在短臂转来时可进入，不把遮挡规则当新教学。
