# 设计稿

> 2026-10-16 可玩性改版定稿。规则来源见 [decisions.md](decisions.md)；改动玩法前需征得用户同意。

## 一句话

路看似相连，就能走过去。

## 目标

- **类型**：等距视角的空间错觉解谜。体验方向参考《纪念碑谷》，玩法、关卡、美术全部原创。
- **体量**：14 关，分 4 章，一遍 40～60 分钟。前两章轻松上手，后两章需要停下来想。
- **平台**：电脑和手机浏览器，打开即玩。
- **体验关键词**：安静、温暖、好看、**值得思考**、不挫败（有撤销和提示兜底）。

首版的教训：每关只有一两个机关、状态不到 10 种、没有岔路和取舍，后半段甚至没有错觉连接，乱点几下就能通关。改版后的每一条规则都是为了避免这些问题。

## 核心规则

### 看起来相邻，就是相邻

相机固定为等距正交视角，从 `(1, 1, 1)` 方向看向场景。每块积木有一个屏幕坐标 `(x - y, z - y)`。

- 两块**可行走路面**的屏幕坐标上下左右相邻，就是相连的。
- 路面顶上压着任何积木时，不可行走。
- 只有标记为路面的积木参与寻路；结构积木只负责构图。

### 玩家做什么

1. 点击机关的金色把手，改变积木在屏幕上的排列。
2. 点击一块路面，小人沿最短路径走过去，路过的光点自动收集。
3. 集齐必需光点后走到灯笼前，点亮灯笼，通关。

## 机关

### 转盘

- 一组积木绕竖直轴，围着一个静态中心格旋转。
- 每次触发顺时针（从上往下看）转 90 度，动画 0.9 秒；被联动且标记 `reverse` 时逆时针转。
- 档位 0～3 循环。大型转盘可以包含整座建筑，用来做「换个角度」。

### 平移台

- 一组积木沿一个轴在若干整数停靠位之间移动。
- 每次触发移到下一个停靠位；到达最后一站后反向，往返循环。
- 动画每格 0.45 秒。沿 `y` 轴是升降台，沿 `x`、`z` 轴是滑块。

### 压板

- 一块带金色边框的静态路面。
- 小人**停在**压板上（路线走完）时触发它绑定的机关一次，效果等同于点击该机关的把手（包括联动）。
- `once: true` 的压板只触发一次，之后边框变暗。
- 绑定的机关正在运动时，本次不触发，压板闪一下。

### 联动

- 转盘和平移台可以声明 `links`：自己被触发时，列出的机关同时被触发一次。
- 联动只传一层：被联动的机关不会再触发它自己的 `links`。
- 转盘被联动时可以标记 `reverse`，表示逆时针转。
- 所有被触发的机关同时开始运动，全部结束后才接受下一个指令。

### 无把手机关

- 转盘和平移台可以不设把手，只能通过联动或压板触发。
- 用来制造间接操作：想动 B，必须找到哪个把手或压板连着 B。

### 乘坐

- 小人**停在**某个机关的积木上时，这个机关被触发（无论来自把手、联动还是压板），小人随积木一起移动；转盘还会让小人的朝向跟着转。
- 运动结束后，小人位于积木的新位置，重新计算连通。
- 小人行走途中不能操作任何机关。
- 关卡必须保证：任何可达状态下，小人所在格子的上方都不会被积木占据（由校验检查）。

## 光点与灯笼

- 光点浮在路面上方，小人**进入**该格（包括路过）即收集。机关积木上的光点随积木移动。
- **必需光点**：集齐才能点亮灯笼。每关 0～3 个，序章可以为 0。
- **选做光点**：第 2 章起每关 1 个，放在需要更深理解才能到达的位置，用于「集齐全部光点」评价。
- 必需光点没集齐就走到灯笼前：灯笼闪烁一下，顶部提示「还差 N 个光点」，可以继续游戏，不算通关。
- 灯笼的亮度随已收集的必需光点逐级增加，给玩家进度感。

## 撤销、步数、评价与提示

- **步数**：每发出一次行走指令或机关操作记 1 步；行走途中改走别处，替换当前这一步，不额外计数。
- **撤销**：撤回最近一步，场景立即恢复到这一步之前的状态（含光点和压板）。机关运动中不能撤销。步数随之减 1。
- **重新开始**：回到开局，清空步数和撤销记录。
- **评价**（每关三项，独立获得、取历史最好）：
  1. 抵达：通关。
  2. 光点：集齐全部光点（含选做）后通关。
  3. 步数：通关时步数不超过该关最少步数（只要求必需光点，由求解器算出）；本局用过提示则不能获得。
- **提示**：点击后，求解器从当前状态算出下一步最优动作并高亮 2 秒（路面或把手）。当前状态已无法通关时（例如一次性压板用错了），改为提示「这条路走不通了，试试撤销」。

## 界面流程

### 标题页

- 背景为第 1 关场景，缓慢漂浮。
- 中央：Seemingly，下方小字「积木错位」，再下方显示已获得的评价总数（如「已点亮 23 / 42」）。
- 按钮：「开始」进入第一个未通关的关卡；「选关」进入选关页。

### 选关页

- 按章分 4 行，每行标注章名；手机端每章 2 列网格。
- 卡片显示编号、关名、三项评价图标（获得为亮，未获得为暗）。
- 解锁规则：通关第 N 关后解锁第 N+1 关；第 1 关始终解锁。未解锁卡片半透明、不可点击。

### 游戏页

- 左上：「编号 · 关名」，下一行小字「步数 7 · 光点 1/2」。
- 右上：「撤销」「提示」「重新开始」「选关」「静音」。手机端收进一个「菜单」按钮，撤销和提示保持在外面。
- 第 1、2、4、5 关底部显示一句操作提示（介绍新内容），其余关卡不显示。
- 键盘：`Z` 或 `Ctrl/⌘ + Z` 撤销，`H` 提示，`R` 重新开始，`Esc` 返回选关页。

### 通关

- 灯笼点亮，光点散开。0.5 秒后顶部出现横幅：「抵达 · 关名」，三项评价依次亮起，显示「步数 9 / 最少 9」。
- 按钮：「下一关」「再试一次」。
- 第 14 关通关后进入结尾：全部灯笼依次亮起，塔亮起，显示「谢谢游玩」和「回到标题」。

## 反馈与手感

| 情况 | 反馈 |
| --- | --- |
| 悬停路面 | 顶板抬起 0.03、变亮，鼠标变成手形 |
| 点击可达路面 | 白色圆圈扩散，小人出发 |
| 点击不可达路面 | 红色圆圈，提示「看起来连不上，换个角度试试」，播放走不通音效 |
| 行走 | 每秒 2.6 格，每格一个音阶音 |
| 收集光点 | 光点飞向灯笼，灯笼亮度增加一级，播放明亮的双音 |
| 必需光点未齐就到灯笼 | 灯笼闪烁，提示「还差 N 个光点」 |
| 机关运动 | 转盘 0.9 秒、平移台每格 0.45 秒，每 90 度或每格一个低音 |
| 乘坐 | 小人随积木移动，脚下影子保持贴合 |
| 撤销 | 场景瞬间恢复，播放一个轻微的倒放音 |
| 提示 | 目标路面或把手金色脉动 2 秒 |
| 抵达终点 | 灯笼琶音，横幅出现 |

## 音乐

全部用 Web Audio 合成（D20～D22）。

### 层次

| 层 | 内容 | 音量（相对音乐总线） |
| --- | --- | --- |
| 和弦铺底 | 每个和弦 3～4 个音，每个音由两个略微失谐的三角波组成，经低通滤波；起音 2 秒、释放 3 秒，换和弦时交叉淡化 | 0.5 |
| 低音 | 和弦根音，低八度正弦波，起音 1 秒 | 0.3 |
| 八音盒 | 每 1.5～4 秒随机落下一个当前音阶的高音，快起音、1.2 秒衰减 | 0.25 |
| 混响 | 代码生成的 2.5 秒衰减脉冲响应，湿声比例 0.35 | — |

### 和弦进行（每个和弦 8 秒，四个循环）

| 章 | 和弦 | 音阶 |
| --- | --- | --- |
| 一 | Cmaj9 → Am9 → Fmaj9 → Gsus2 | C 大调五声 |
| 二 | Am9 → Fmaj7 → Cmaj7 → G6 | A 小调五声 |
| 三 | Dm9 → G7sus4 → Em7 → Am7 | D 多利亚 |
| 四 | E♭maj9 → Cm9 → A♭maj7 → B♭sus2 | E♭ 大调五声 |

切换到不同章的关卡时，用 3 秒交叉淡化到新的调式。

### 操作音

- **脚步**：按当前和弦音依次上行（到顶回到起点），短促的拨弦音，音量很低。
- **机关**：当前和弦的根音和五度，低八度，木质感。
- **光点**：当前音阶中两个相邻的高音。
- **灯笼**：当前和弦的上行琶音。
- **走不通**：低音区的一个柔和音（音阶第二级），不刺耳。
- **撤销**：一个音高下滑的短音。

### 混音

- 音乐总线 0.18、音效总线 0.5，再进入主音量和压缩器，防止叠加时破音。
- 用提前调度（每 100 毫秒向后安排 0.3 秒内的音符），保证节奏稳定。
- 静音时停止全部音源；取消静音后从当前和弦重新淡入。
