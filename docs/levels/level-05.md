# 第 5 关 · 乘风

## 关名、章节、教学点

- 第二章「转动」，第 5 关。
- 教学点：乘坐。桥的中心是实心立柱，站不上去，两条桥臂互不相连，只有站在桥臂上一起转才能过去。

## 原来如此

- 主线：站在桥臂上转动，桥会带着你走。先被带到南边拿光点，再被带到东边登上灯笼塔。
- 选做光点：在另一条桥臂上。先不上桥，原地把桥转两次，让另一条桥臂转到自己面前，再登上它；之后乘着它去南边，再到东边。

## 屏幕草图

```text
0@
  0
    0
      c

          cO
    2o      5G
```

两个 `c` 是桥臂，中间的空格是实心立柱。桥转动时，桥臂依次经过西、南、东、北四个位置。

## 积木清单

- 西岛：地面 `x -1～3、z 1～3`；陶土步道（高度 0）`(0,0,2)` 起点、`(1,0,2)`、`(2,0,2)`。
- 渡船：地面 `x 5～7、z 3～5`；青绿立柱 `(6,0..2,4)`（顶部 `(6,2,4)` 是转盘中心，实心）。
- 南台：地面 `x 5～7、z 6～8`；陶土柱 `(6,0..1,6)`；路面（高度 2）`(6,2,6)`。
- 灯笼塔：地面 `x 10～12、z 6～8`（岩层深 6）；粉色柱子 `(11,0..4,7)`；塔顶（高度 5）`(11,5,7)` 是终点。

## 机关清单

| 编号 | 类型 | 中心 | 积木偏移 | 初始档位 | 把手 |
| --- | --- | --- | --- | --- | --- |
| ferry | 转盘 | `(6,2,4)`（实心，不可站） | `(-1,0,0)`（桥臂 0）、`(1,0,0)`（桥臂 1） | 0 | `(6,0,4)` 的 `x` 面 |

桥臂 0 依次位于：西 → 南 → 东 → 北；桥臂 1 依次位于：东 → 北 → 西 → 南。

## 光点清单

| 编号 | 位置 | 类型 |
| --- | --- | --- |
| orb-0 | 桥臂 1（ferry#1） | 选做 |
| orb-1 | `(6,2,6)` 南台 | 必需 |

## 其他元素

无。

## 标准解法

1. 走到 `(5,2,4)`：登上位于西侧的桥臂 0。
2. 转动 ferry：桥臂 0 带着小人转到南侧。
3. 走到 `(6,2,6)`：拿南台光点。
4. 走回 `(6,2,5)`：回到南侧的桥臂 0 上。
5. 转动 ferry：桥臂 0 带着小人转到东侧。
6. 走到 `(11,5,7)`：经错觉连接登上灯笼塔。

选做路线（8 步）：转动 → 转动（桥臂 1 转到西侧）→ 登上桥臂 1（拿选做光点）→ 转动（被带到南侧）→ 拿南台光点 → 回到桥臂 1 → 转动（被带到东侧）→ 登塔。

## 干扰与陷阱

- 不上桥就转，桥臂会离开，起点和南台之间没有任何别的路。
- 站在南台上转桥，桥臂离开后会被困住，要再转一次让另一条桥臂转到南侧，或者撤销。

## 参考实现

```ts
import { defineLevel } from './builders'

export default defineLevel({
  id: 'level-05',
  title: '乘风',
  chapter: 2,
  hints: ['站在桥上转动，桥会带着你走'],
  build: (b) => {
    b.island({ x: [-1, 3], z: [1, 3], y: -1 })
    b.path([0, 0, 2], 'terracotta')
    b.path([1, 0, 2], 'terracotta')
    b.path([2, 0, 2], 'terracotta')

    b.island({ x: [5, 7], z: [3, 5], y: -1 })
    b.column({ x: 6, z: 4, from: 0, to: 2 }, 'teal')
    b.rotator({
      id: 'ferry',
      pivot: [6, 2, 4],
      blocks: [{ offset: [-1, 0, 0] }, { offset: [1, 0, 0] }],
      handle: { block: [6, 0, 4], face: 'x' },
    })
    b.orb({ mechanism: 'ferry', block: 1, optional: true })

    b.island({ x: [5, 7], z: [6, 8], y: -1 })
    b.column({ x: 6, z: 6, from: 0, to: 1 }, 'terracotta')
    b.path([6, 2, 6], 'terracotta')
    b.orb({ tile: [6, 2, 6] })

    b.island({ x: [10, 12], z: [6, 8], y: -1, depth: 6 })
    b.column({ x: 11, z: 7, from: 0, to: 4 }, 'rose')
    b.path([11, 5, 7], 'rose')

    b.start([0, 0, 2])
    b.goal([11, 5, 7])
  },
  solution: [
    { type: 'walk', to: [5, 2, 4] },
    { type: 'operate', mechanism: 'ferry' },
    { type: 'walk', to: [6, 2, 6] },
    { type: 'walk', to: [6, 2, 5] },
    { type: 'operate', mechanism: 'ferry' },
    { type: 'walk', to: [11, 5, 7] },
  ],
})
```
