# 第 3 关 · 随行

T6.12v4 教学更新：主线不再常驻显示下方参考实现中的hints。首次教学与收起条件以[设计稿](../design.md#游戏页)为准，已学状态跨撤销、重开、重进和刷新保留；仅改变操作说明，不改变本关谜题、标准解或提示按钮。

## 状态与适用任务

T6.12r 已按本稿实现。运行中的第三关为「随行」、revision 3。历史设计见 `git show 734c8a2:docs/levels/level-03.md`。

## 教学点与原来如此

第一章章末。从第二关「人站在静台上，把出口转过来」，转为 **人也可以随建筑移动；站到平台上，才能抵达另一边**。这关必须乘坐，但不要求换乘或下台控制另一机关。中心粉色轴为实心、没有浅色顶板，不能站；不可把它改成路面。

## 屏幕草图

```text
(0,2) 0@入口 — (1,2) 1o乘台  [实心轴 (2,2)]  (3,2) 乘台档2 — (4,2) 2G
                                ↘
                          (2,3) 乘台档1
                          (2,1) 乘台档3
```

乘台的屏幕落点 `(1,2)→(2,3)→(3,2)→(2,1)`，高度均为 1；入口高度 0，灯笼高度 2。南侧另有 `(2,4)@2` 的静态尽头可探索，档 1 时与乘台相连，没有光点或出口。柱与下方实心支撑不是路面。

## 积木、机关与目标清单

- 入口基座 `x[-1,1],z[1,3],y=-1,depth=2`；主基座 `x[2,6],z[2,6],y=-1,depth=3`。
- 起点 `(0,0,2)`；实心轴 `(3,0,3)`、`(3,1,3)`；控制底座 `(6,0,5)`。
- `ferry` 转盘：中心 `(3,1,3)`，档 0；路面偏移 `(-1,0,0)`，其下实心支撑 `(-1,-1,0)`；把手 `(6,0,5)` 的 z 面，不限次数、无联动。
- 灯笼路面 `(6,2,4)`，下方柱 `(6,0,4)`、`(6,1,4)`。
- 干扰南台路面 `(4,2,6)`，下方柱 `(4,0,6)`、`(4,1,6)`，可往返但不是终点。
- 一处必需光点在 `ferry#0`，随平台运动。无选做、门、箱子、压板、单向格或巡逻者。
- 地面树 `(-1,-1,3)`、花 `(5,-1,5)`，塔 x 面窗 `(6,0,4)`；完整坐标见参考实现。

## 标准解法与干扰路线

| 步 | 动作 | 用意 |
| --- | --- | --- |
| 1 | 走到 `(2,1,3)` | 登上 ferry#0，取移动平台上的光点 |
| 2 | ferry 一次 | 乘到南侧，观察小人随台运动 |
| 3 | ferry 一次 | 继续乘到东侧，接上灯笼 |
| 4 | 走到 `(6,2,4)` | 经高低错觉接口登塔点灯 |

在入口先转平台，会把载具送走；继续转回可以恢复，不算失败或死局。在地面等平台转到灯笼一侧，人仍到不了对岸。中心没有顶板，点击轴不触发行走，不能补路。两次操作期间，角色格子始终是 `ferry#0`。

第一转后可以走到南台 `(4,2,6)`，但那里没有灯笼；必须返回同一乘台 `(3,1,4)` 再继续。多出的来回两次行走不计入标准四步，构成第三关起要求的可探索干扰路线；不引入换到另一载具的要求。

## 指标与难度目标

2026-10-21 校验通过，随机种子 20261016、500 次、30 步。

| 最少 / 全收集 | 状态 / 死局 | 随机通关率 | 错觉 / 取舍 |
| --- | --- | --- | --- |
| 4 / 4 | 17 / 0 | 56.0% | 2 / 2 |

第一章没有状态数和取舍下限。这是短乘坐教学，深入规划从第四关开始；不要为满足第二章门槛而改本关 chapter、指标或布局。禁用把手无解；搜索时过滤「站在机关上时 operate」后也无解，证明乘坐是必要条件。

```ts
'level-03': { minActions: 4, minActionsAll: 4, illusionsMin: 2 },
```

## 实现验收

- `revision: 3`，只清除旧第三关评价，保留其余记录；第一章 courtyard 乐句不变。
- 标准四步、收光撤销、乘坐前中后位置、运动中撤销失败、到位后撤销恢复档位与站位须测试；额外走南台、返回同一平台仍能通关，不能误当永久死局。
- 反事实搜索只过滤动作，不另写连通规则：以 `initialState` 起步，用 `legalActions/applyAction/stateKey` 扩展；过滤 `action.type === 'operate' && state.at.startsWith(action.mechanism + '#')`，不能搜到 won。禁止把手也不能通关。
- 桌面与手机检查前、中、后帧，角色贴合平台、朝向随之改变；无顶板的中心不会被误认成路面。开局光点和灯笼可见，转轮可点。
- T6.12v4 起乘坐说明只作首次教学，载人到位后收起；只讲操作能力，不说「转两次」。不引入新音色或更改规则；T6.12r 的原实现记录保留。

## 参考实现

```ts
import { defineLevel } from './builders'

export default defineLevel({
  id: 'level-03',
  title: '随行',
  chapter: 1,
  revision: 3,
  soundtrack: 'courtyard',
  hints: ['浅色顶板是可以站立的路面', '站在移动的积木上，小人会随它一起移动'],
  build: (b) => {
    b.island({ x: [-1, 1], z: [1, 3], y: -1, depth: 2 })
    b.path([0, 0, 2], 'terracotta')
    b.island({ x: [2, 6], z: [2, 6], y: -1, depth: 3 })
    b.column({ x: 3, z: 3, from: 0, to: 1 }, 'rose')
    b.solid([6, 0, 5], 'terracotta')
    b.rotator({
      id: 'ferry',
      pivot: [3, 1, 3],
      blocks: [{ offset: [-1, 0, 0] }, { offset: [-1, -1, 0], kind: 'solid', color: 'teal' }],
      handle: { block: [6, 0, 5], face: 'z' },
    })
    b.orb({ mechanism: 'ferry', block: 0 })
    b.column({ x: 4, z: 6, from: 0, to: 1 }, 'rose')
    b.path([4, 2, 6], 'rose')
    b.column({ x: 6, z: 4, from: 0, to: 1 }, 'rose')
    b.path([6, 2, 4], 'rose')
    b.tree([-1, -1, 3])
    b.flower([5, -1, 5])
    b.window({ pos: [6, 0, 4], face: 'x' })
    b.start([0, 0, 2])
    b.goal([6, 2, 4])
  },
  solution: [
    { type: 'walk', to: [2, 1, 3] },
    { type: 'operate', mechanism: 'ferry' },
    { type: 'operate', mechanism: 'ferry' },
    { type: 'walk', to: [6, 2, 4] },
  ],
})
```
