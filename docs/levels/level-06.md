## 关名、章节、教学点

- 第二章「转动」章末，关名仍为「两难」。只使用已经学过的转盘与乘坐，不引入联动、门、箱子或新连通规则。
- 从“转一座桥，去下一个目标”推进到“借另一座桥，换到同一机关的另一处路面”。
- 没有常驻解法提示；按钮提示和无限撤销保留。

## 原来如此

西转盘的低桥与高台属于同一机关，却无法在机关内部走过去；必须下低桥、借东转盘中转，等西高台回来后从另一个方向重新登上它。

第二层认识：东转盘的外角和内端旋转后的落点不同。先站到外角，再转到南侧，才能接上西高台。选做则要求先上高台，再退开东桥，露出原本被它挡住的低处落脚点；拿到光点后返回同一高台。

## 屏幕草图

屏幕 `(a,b)=(x-y,z-y)`；`W` 是西低桥，`H` 是西高台，`e` 是东桥；数字是路面高度。

```text
                 (4,-5) 2G

(4,0) 1o
                            (5,1) e  (6,1) e   东桥初始档 3
(0,2) 1@  (1,2) 2W   [西轴 (2,2)]  [东轴 (5,2)]  (7,2) 3X

                 (4,3) 1O  西折臂低处落脚点，开局可见
                 (4,4) 4H
```

- 西低桥绕 `(2,2)`：`(1,2) → (2,3) → (3,2) → (2,1)`，高度 2。
- 西高台并非低桥同一水平面的对称桥臂：`(4,4) → (4,-4) → (-4,-4) → (-4,4)`，高度 4。
- 东桥外角在档 0 为 `(4,1)`，档 1 为 `(4,3)`，档 2 为 `(6,3)`，档 3 为 `(6,1)`；高度 2。
- 西档 2、东档 0 时，西低桥接入东桥，再到必需光点。
- 西档 0、东档 1 时，东桥外角向下接入西高台。西档 1 时高台接到灯笼。

## 积木与岛屿清单

具体坐标、颜色和机关实心构件见下方参考实现，属于谜题的一部分，不得仅当装饰删掉。

| 位置 | 路面世界坐标 | 用途 |
| --- | --- | --- |
| 入口 | `(1,1,3)` | 起点，陶土 |
| 北台 | `(5,1,1)` | 必需光点，陶土 |
| 东塔 | `(10,3,5)` | 实心装饰塔，不铺浅色顶板，不是路面 |
| 灯笼台 | `(6,2,-3)` | 终点，玫瑰粉 |

静态路面下的柱子由高度 0 补到路面下方。两条长岛屿（`x 1～9,z 0～1` 和 `x 1～9,z 6～7`）通过两侧基梁围成空庭；`x 5～7,z -4～-2` 的后岛承接灯笼台。岛屿顶面均为 `y=-1`。穿庭基梁位于 `z=4,y=-1`。开局可见全部光点和灯笼。

## 机关清单

| 编号 | 中心 | 初始档位 | 路面偏移 | 把手 |
| --- | --- | --- | --- | --- |
| west | `(4,2,4)`，实心中心 | 0 | `(-1,0,0)` 低桥、`(4,2,4)` 高台、`(1,-1,0)` 低处落脚点 | `(6,0,7)` 的 z 面 |
| east | `(7,2,4)`，实心中心 | 3 | `(-1,0,0)` 内端、`(-1,0,-1)` 外角 | `(9,1,6)` 的 z 面 |

两者都独立、无限次顺时针转动，无联动。西转盘前三块积木是路面（低桥、高台、低处落脚点）；其余为不可行走的折臂框架，连到高台下方，其绕开东轴的凹口保证各档位无重叠。中心、框架均不铺路面顶板。

## 光点与其他元素

- `orb-0`：北台 `(5,1,1)`，必需。
- `orb-1`：`west#2`，偏移 `(1,-1,0)` 的低处落脚点，选做；开局位置 `(5,1,4)`，随西转盘移动。
- 无箱子、门、压板、单向格、限次把手、巡逻者。
- 树、花与两扇窗仅点缀建筑，不暗示额外通路。

## 标准解法

| 步 | 动作 | 为什么 |
| --- | --- | --- |
| 1 | 走到 `(3,2,4)` | 登西低桥 |
| 2～3 | west 两次 | 乘低桥到东侧 |
| 4 | east 一次 | 东桥转到档 0，接住低桥 |
| 5 | 走到 `(5,1,1)` | 经东桥拿必需光点 |
| 6 | 走到 `(6,2,3)` | 返回东桥外角，而非回西低桥 |
| 7～8 | west 两次 | 人留在东桥，让西高台回到空庭前方 |
| 9 | east 一次 | 外角带人到 `(6,2,5)`，接上高台 |
| 10 | 走到 `(8,4,8)` | 经错觉连接登上西高台 |
| 11 | west 一次 | 乘高台到北侧 |
| 12 | 走到 `(6,2,-3)` | 点亮灯笼 |

第 7～8 步与第 9 步可交换。全收集 15 步：前 10 步同主线，先登上高台；第 11 步将 east 从档 1 转到档 2，移开挡住低处落脚点的外角；第 12 步走到 `(5,1,4)` 收集选做光点；第 13 步回到 `(8,4,8)`；第 14 步 west 一次；第 15 步灯笼。与上一版“绕塔取点”相比，路线更短，关键判断变成“先登高台，再移动刚才送自己的桥”。

## 干扰与陷阱

- 入口就转 west：高台虽然看起来靠近，但入口只接低桥，不能从低桥内部走到高台。
- 拿光点后原路回低桥：会继续在低桥的四个落点之间转，无法抵达终点；要把东桥当中转站。
- 东桥站错端点：仍然可以调整或多走一步，不制造永久死局；最少步数要求预先选择外角。
- 选做光点开局可见，但东桥到档 1 后外角挡住低处落脚点；先登高台，再将东桥退开，才能进入。直接点击被挡住的位置不能通行。
- 选做路线提前应用既有全局遮挡规则，不改变规则；第五章仍是正式教学重点。初始光点与折臂轨迹可见，不让玩家猜凭空出现的物体。
- 主线不靠遮挡断路作为解题发现，不藏起初始光点，不禁用撤销。

## 声音目标

仅第六关使用 `courtyard` 声景，其余关卡保持原有声音。参考的是构成与交互方法，不使用参考作品的录音或旋律：

- [《纪念碑谷 3》音频作者访谈](https://www.asoundeffect.com/monument-valley-3-game-audio/)：借鉴材质层与乐音层结合、环境与音乐轮流成为重点的做法。
- [《花园之间》开发商的沉思型视听展示](https://www.thevoxelagents.com/gardensbetween/)：借鉴安静、可停留的氛围目标。

采用 96 秒原创乐句，八个低音区和弦，每段 12 秒；22 个键盘音事件，有力度、左右位置和长短停顿，事件表以 `audio/theory.ts` 为准。末段以低音区的开放和声回到开头，不靠八秒一换的持续低音或随机高音填充时间。

键盘音用基频与逐渐衰减的非整数泛音合成，模拟柔软敲击感；持续声层改为平滑的谐波波形，四秒起音、五秒释放，不叠加独立的低音振荡器。第六关层增益 2.2，沿用引擎原有音乐总线、主音量、压缩器和混响。

脚步是很轻的木质触感，不再每步播放一段上行音阶；转动开始有 0.9 秒材质声，到位有柔和共鸣，两把手采用根音与五度音区。光点与灯笼用同一键盘音色回应，音高由当时实际和弦决定。静音、恢复、切换章节仍沿用音频引擎；听感最终由用户确认。

import { defineLevel } from './builders'
import type { Vec3 } from './types'

export default defineLevel({
  id: 'level-06',
  title: '两难',
  chapter: 2,
  revision: 3,
  soundtrack: 'courtyard',
  build: (b) => {
    b.island({ x: [1, 9], z: [0, 1], y: -1, depth: 1.8 })
    b.island({ x: [1, 9], z: [6, 7], y: -1, depth: 2.2 })
    b.island({ x: [5, 7], z: [-4, -2], y: -1, depth: 2 })
    for (let z = 2; z <= 5; z++) {
      b.solid([1, -1, z], 'terracotta')
      b.solid([9, -1, z], 'terracotta')
    }
    for (let x = 2; x <= 8; x++) b.solid([x, -1, 4], 'terracotta')

    const platforms: { pos: Vec3; color: 'terracotta' | 'rose'; walkable?: boolean }[] = [
      { pos: [1, 1, 3], color: 'terracotta' },
      { pos: [5, 1, 1], color: 'terracotta' },
      { pos: [10, 3, 5], color: 'rose', walkable: false },
      { pos: [6, 2, -3], color: 'rose' },
    ]
    for (const {
      pos: [x, y, z],
      color,
      walkable = true,
    } of platforms) {
      b.column({ x, z, from: 0, to: y - 1 }, color)
      if (walkable) b.path([x, y, z], color)
      else b.solid([x, y, z], color)
    }

    b.column({ x: 4, z: 4, from: 0, to: 2 }, 'teal')
    b.solid([6, 0, 7], 'teal')
    const frame: Vec3[] = [
      [2, -1, 0],
      [2, -1, -1],
      [3, -1, -1],
      [4, -1, -1],
      [4, -1, 0],
      [4, -1, 1],
      [4, -1, 2],
      [4, -1, 3],
      [4, -1, 4],
      [4, 0, 4],
      [4, 1, 4],
    ]
    b.rotator({
      id: 'west',
      pivot: [4, 2, 4],
      blocks: [
        { offset: [-1, 0, 0] },
        { offset: [4, 2, 4] },

      id: 'east',
      pivot: [7, 2, 4],
