# 美术方向

> 小样的画面已经确认可行。本文记录当前做法和后续要改进的地方，正式开发时以此为准。

## 风格

暖色、低饱和的积木世界，漂浮在黄昏的天空里。画面来自几何体、配色和光影，不依赖精细模型。

- **积木感**：方块带小圆角，相邻方块之间留出细缝，像真的积木拼起来。
- **安静**：画面元素少，留白多，动效都很慢。
- **温暖**：主色是陶土、沙色、玫瑰粉，冷色只用青绿做点缀，标记机关。

参考方向：《纪念碑谷》的构图和留白、《Townscaper》的温暖配色。只参考气质，不借用任何素材。

## 配色

定义在 `src/game/render/palette.ts`，新增颜色先加到这里。

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| path | `#f7ecd6` | 可行走路面的顶板 |
| cream | `#fff7ea` | 悬停路面、角色、门框 |
| sand | `#ecc795` | 岛屿地面 |
| terracotta | `#de8d64` | 低处步道、终点基座、角色帽子 |
| rose | `#e9a7a1` | 高塔 |
| teal / tealLight | `#5f9894` / `#8cc0b6` | 机关（转盘立柱、桥臂） |
| glow | `#ffd98a` | 可交互把手、终点光 |
| plum / plumDeep | `#7a5f86` / `#5b4569` | 窗洞、暗部 |
| leaf / leafDeep / trunk | `#9cbf8f` / `#7aa477` / `#a8745a` | 树木 |

约定：

- **金色只用于可交互的东西**，玩家看到金色就知道可以点。
- **青绿只用于会动的积木**，让玩家一眼看出机关范围。
- 路面统一用浅色顶板，和结构积木区分开。

## 积木与场景

- 积木尺寸 0.98，圆角 0.07，所有积木共用同一份几何体。
- 可行走积木顶上加一块 0.84 见方的浅色顶板，悬停时抬起 0.03。
- 岛屿底部是逐层收窄的阶梯岩层，颜色从沙色过渡到深紫。
- 装饰物：低多边形树、小花、拱形窗洞、飘动的云、漂浮的光点。装饰物不能遮挡路面，也不能放在错觉连接处附近。

## 光影

- 半球光提供天空暖色和地面紫色的环境光，平行光从左上前方打出主光和阴影。
- 三个可见面形成明确的明暗层次：顶面最亮，左前面次之，右前面最暗。
- 阴影贴图 2048，后续低画质档可以降到 1024 或关闭阴影。
- 背景是 CSS 渐变（米白、蜜桃、淡紫），四角加轻微暗角，不在 3D 场景里画天空。

## 角色（待优化）

小样中的小人偏小，白色身体和米色路面几乎同色，看不清楚。正式开发时按以下方向改进：

1. **提高对比度**：身体换成和路面明显不同的颜色，比如深色或饱和的主色；帽子保留陶土色作为识别点。
2. **放大约 1.3 倍**，在手机屏幕上也要一眼找到。
3. **脚下加柔和的圆形影子**，在任何底色上都能和地面分开。
4. **加上眼睛和走路动作**：身体左右轻摆，到达时有一个小停顿。
5. **轮廓保持简洁**：几何体拼出，不追求细节，和积木风格一致。

验收标准：在小样场景的每一块路面上，缩小到手机尺寸时都能立刻看清小人的位置和朝向。

## 界面

- 文字只用中文加少量英文标题，字体用系统字体（苹方、微软雅黑）。
- 按钮和提示条都是半透明的圆角胶囊，带背景模糊。
- 提示不挡场景中央；通关横幅出现在顶部，延迟半秒淡入。
- 手机端提示条改为纵向排列。
