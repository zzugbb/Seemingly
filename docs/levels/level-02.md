# 第 2 关 · 看似

## T6.12f 校准

用户要求持续完成前六关校准，当前助手作为指定设计者继续第二关；保留第一关入门、第六关已认可结果。本轮将原两步单光点路线变为三步双光点的三级回廊，强化同一条屏幕路线可以连接不同高度的认识，仍不加入机关。

## 关名、章节、教学点

第一章「看似」第二关，正式教学静态错觉连接：判断浅色路面在画面中是否相接，而不是沿三维高度找楼梯。只使用行走、光点和灯笼。

## 原来如此

三级回廊在空间中分开，屏幕上相接的地方却都能走过去；从高台另一侧还能跨到较低的灯笼廊。

## 屏幕草图

数字为高度，`o` 必需光点、`@` 起点、`G` 终点；坐标 `(a,b)=(x-y,z-y)`。

```text
b\a  0   1   2   3   4   5   6
 0                   1   1   1G
 1   0   0   0   3   3   4
 2   0@          3o      4o
```

三个接口：低步道 `(2,1)@0` 到侧廊 `(3,1)@3`；侧廊 `(4,1)@3` 到四层平台 `(5,1)@4`；四层平台 `(5,1)@4` 返回灯笼廊 `(5,0)@1`。均满足屏幕靠下的路面不比靠上的低。两处光点位于不同支路尽头，自动寻路不会把它们一次顺路捡完。

## 积木清单

- 西岛地面 `x -1～3、z -1～3、y=-1`；陶土路面 `(0,0,2)`、`(0,0,1)`、`(1,0,1)`、`(2,0,1)`。
- 高廊岛 `x 5～10、z 3～7、y=-1、深度 4`；三层路面 `(6,3,4)`、`(7,3,4)`、`(6,3,5)`，下方 `y=0～2` 补粉色柱；四层路面 `(9,4,5)`、`(9,4,6)`，下方 `y=0～3` 补粉色柱。
- 灯笼岛 `x 4～8、z 0～1、y=-1`；低廊 `(5,1,1)`、`(6,1,1)`、`(7,1,1)`，下方 `y=0` 陶土柱。
- 起点 `(0,0,2)`，灯笼 `(7,1,1)`。

## 机关清单

无。

## 光点清单

| 编号 | 世界坐标 | 类型 |
| --- | --- | --- |
| orb-0 | `(6,3,5)`，三层侧廊尽头 | 必需 |
| orb-1 | `(9,4,6)`，四层平台尽头 | 必需 |

## 其他元素

无箱子、门、压板、单向格或巡逻者。五处装饰：树 `(-1,-1,3)`，花 `(10,-1,7)`，窗 `(6,1,5)` 的 z 面、`(7,1,4)` 的 x 面、`(9,2,6)` 的 z 面；不挡路或光点。

## 标准解法

1. 走到 `(6,3,5)`：从低步道跨上侧廊，收集第一处光点。
2. 走到 `(9,4,6)`：经过 `(9,4,5)`，沿第二处错觉接口登上四层平台，收集第二处。
3. 走到 `(7,1,1)`：从高台跨回低廊，经 `(6,1,1)` 到灯笼。

两处光点可交换顺序，不设置隐含正确顺序。标准路线选择依次跨上、再跨出的过程，方便观察三处不同高度的连接。

## 干扰与陷阱

- 先走灯笼可抵达，但提示「还差 2 个光点」；只拿一处时仍不能通关。
- 三层侧廊拿完后要返回主廊继续，浅色尽头不代表下一关入口。
- 高台朝屏幕上方的出口可以走到较低的灯笼廊；不能用现实高度差判断它不可通行。
- 无永久死局，不用遮挡、单向格或机关增加教学负担；两光点开局均可见。

```ts
import { defineLevel } from './builders'

export default defineLevel({
  id: 'level-02',
  title: '看似',
  chapter: 1,
  revision: 2,
  soundtrack: 'courtyard',
  hints: ['看起来连着，就能走过去'],
  build: (b) => {
    b.island({ x: [-1, 3], z: [-1, 3], y: -1 })
    b.path([0, 0, 2], 'terracotta')
    b.path([0, 0, 1], 'terracotta')
    b.path([1, 0, 1], 'terracotta')
    b.path([2, 0, 1], 'terracotta')

    b.island({ x: [5, 10], z: [3, 7], y: -1, depth: 4 })
    b.column({ x: 6, z: 4, from: 0, to: 2 }, 'rose')
    b.column({ x: 7, z: 4, from: 0, to: 2 }, 'rose')
    b.column({ x: 6, z: 5, from: 0, to: 2 }, 'rose')
    b.path([6, 3, 4], 'rose')
    b.path([7, 3, 4], 'rose')
    b.path([6, 3, 5], 'rose')
    b.orb({ tile: [6, 3, 5] })
    for (const z of [5, 6]) {
      b.column({ x: 9, z, from: 0, to: 3 }, 'rose')
      b.path([9, 4, z], 'rose')
    }
    b.orb({ tile: [9, 4, 6] })

    b.island({ x: [4, 8], z: [0, 1], y: -1 })
    b.column({ x: 5, z: 1, from: 0, to: 0 }, 'terracotta')
    b.column({ x: 6, z: 1, from: 0, to: 0 }, 'terracotta')
    b.column({ x: 7, z: 1, from: 0, to: 0 }, 'terracotta')
    b.path([5, 1, 1], 'terracotta')
    b.path([6, 1, 1], 'terracotta')
    b.path([7, 1, 1], 'terracotta')

    b.tree([-1, -1, 3])
    b.flower([10, -1, 7])
    b.window({ pos: [9, 2, 6], face: 'z' })
    b.window({ pos: [6, 1, 5], face: 'z' })
    b.window({ pos: [7, 1, 4], face: 'x' })

    b.start([0, 0, 2])
    b.goal([7, 1, 1])
  },
  solution: [
    { type: 'walk', to: [6, 3, 5] },
    { type: 'walk', to: [9, 4, 6] },
    { type: 'walk', to: [7, 1, 1] },
  ],
})
```
